Q1. Size of gravel is defined in mm as

  1. A. 0.002 - 0.20
  2. B. 76.2 - 102.5
  3. C. 4.75 - 7.62
  4. D. 0.20 - 4.75
Answer: C. 4.75 - 7.62

Q2. Size of sand is defined in mm as

  1. A. 76.2 - 102.5
  2. B. 0.002 - 0.20
  3. C. 4.75 - 7.62
  4. D. 0.075 - 4.75
Answer: B. 0.002 - 0.20

Q3. Void ratio "e" is determined in a soil sample by

  1. A. Vv/V
  2. B. Vv/Vs
  3. C. V - Vs
  4. D. Vd - Vs
Answer: B. Vv/Vs

Q4. Porosity "n" is determined in a soil sample by

  1. A. Vv/V
  2. B. Vv/Vs
  3. C. V - Vs
  4. D. Vd - Vs
Answer: A. Vv/V

Q5. Relation between void ratio and porosity is expressed as

  1. A. e = n/(1 - n)
  2. B. e = (n - 1)/n
  3. C. e = (1 - n)/n
  4. D. e = n/(n - 1)
Answer: A. e = n/(1 - n)

Q6. Relation between porosity and void ratio is expressed as

  1. A. n = e/(1 - e)
  2. B. n = e/(e - 1)
  3. C. n = e/(1 + e)
  4. D. n = (e + 1)/e
Answer: C. n = e/(1 + e)

Q7. Degree of saturation is expressed as

  1. A. s = Vv/Vs
  2. B. s = Vw/Vs
  3. C. s = Vv/Vw
  4. D. s = Vw/Vv
Answer: D. s = Vw/Vv

Q8. Dry density is expressed by

  1. A. γd = Wd/V
  2. B. γd = Ws/V
  3. C. γd = Ws/Vs
  4. D. γd = Vs/Ws
Answer: A. γd = Wd/V

Q9. Dry density of a soil sample is expressed by

  1. A. γd = (1 + m)/γ
  2. B. γd = γ/(1 - m)
  3. C. γd = γ/(1 + m)
  4. D. γd = (1 - m)/γ
Answer: C. γd = γ/(1 + m)

Q10. Moisture content in a soil sample is expressed by

  1. A. m = W/Ww
  2. B. m = Ww/W
  3. C. m = W/Wd
  4. D. m = Ww/Wd
Answer: D. m = Ww/Wd
