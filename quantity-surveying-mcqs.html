Q1. An art to collect data about material and cost required for a project is called

  1. A. Quantity survey
  2. B. Estimation
  3. C. S.D.O
  4. D. a and b
Answer: A. Quantity survey

Q2. Quality of any material and construction work is described by .....

  1. A. Cost
  2. B. Specifications
  3. C. Drawing
  4. D. all of these
Answer: B. Specifications

Q3. Such estimate is prepared to get administrative approval.

  1. A. Revised
  2. B. Detailed
  3. C. Rough Cost
  4. D. All of these
Answer: C. Rough Cost

Q4. Horizontal distance between centroids of the sections of cutting and filling is termed as

  1. A. I.M.P
  2. B. Interval
  3. C. Lead
  4. D. Lift
Answer: C. Lead

Q5. A prepared surface of soil which receives load of traffic from pacca road is called

  1. A. Sub-grade
  2. B. Topping
  3. C. Sub-base
  4. D. Base
Answer: A. Sub-grade

Q6. Overall cost of any item of work is determined per unit quantity of work by

  1. A. Tender
  2. B. Analysis of rates
  3. C. Quatation
  4. D. Estimate
Answer: B. Analysis of rates

Q7. Lowest level inside the sewer pipe is called

  1. A. Bed level
  2. B. Crest level
  3. C. Invert level
  4. D. Minimum level
Answer: C. Invert level

Q8. The process of assessing the present value of a property is called

  1. A. Valuation
  2. B. Estimate
  3. C. Analysis
  4. D. All of these
Answer: A. Valuation

Q9. A person whose job is to calculate quantities for a project is called

  1. A. Quantity surveyor
  2. B. Estimator
  3. C. S.D.O
  4. D. a and b
Answer: D. a and b

Q10. Specifications are essential part of

  1. A. Contract
  2. B. Estimate
  3. C. Tender
  4. D. all of these
Answer: C. Tender

Q11. Such estimate is prepared to get technical sanction.

  1. A. Rough Cost
  2. B. Revised
  3. C. Detailed
  4. D. All of these
Answer: C. Detailed

Q12. Vertical distance between centroids of the sections of cutting and filling is termed as

  1. A. Lead
  2. B. Interval
  3. C. I.M.P
  4. D. Lift
Answer: D. Lift

Q13. This is provided in the construction of road if soil is weak.

  1. A. Sub-grade
  2. B. Base
  3. C. Topping
  4. D. Sub-base
Answer: D. Sub-base

Q14. The volume of one bag of cement in M.K.S system is to be

  1. A. .025 cum
  2. B. .35 cum
  3. C. .035 cum
  4. D. .25 cum
Answer: C. .035 cum

Q15. Construction work of a sewer line should be started from ................... side.

  1. A. Upper side
  2. B. Middle side
  3. C. End side
  4. D. Any where
Answer: C. End side

Q16. Actual expenditure on construction of a building is called its

  1. A. Gross value
  2. B. Value
  3. C. Scrap value
  4. D. Cost
Answer: D. Cost

Q17. Necessary data for preparing an estimate of a project is

  1. A. Rates
  2. B. Drawings
  3. C. Specifications
  4. D. All of these
Answer: D. All of these

Q18. Type of specifications is

  1. A. Detailed
  2. B. Standard
  3. C. General
  4. D. All of these
Answer: D. All of these

Q19. Area occupied by walls is ------------- in the plinth area.

  1. A. Included
  2. B. Excluded
  3. C. a or b
  4. D. a and b
Answer: A. Included

Q20. More accurate method of calculating earth work is

  1. A. Mean depth
  2. B. Mean area
  3. C. Prismoidal
  4. D. Graphical
Answer: C. Prismoidal

Q21. Compulsory part of structure of road which is responsible to protect sub grade is called

  1. A. Base
  2. B. Sub-base
  3. C. Sub-grade
  4. D. Topping
Answer: A. Base

Q22. Volume of one bag of cement is;

  1. A. 3 cft
  2. B. 2.5 cft
  3. C. 1.25 cft
  4. D. 1.5 cft
Answer: C. 1.25 cft

Q23. Longitudinal slope of a sewer line is called

  1. A. Country slope
  2. B. Gradient
  3. C. Cross slope
  4. D. Camber
Answer: B. Gradient

Q24. Present market value of the property is called its

  1. A. Cost
  2. B. Scrap value
  3. C. Gross value
  4. D. Value
Answer: D. Value

Q25. Design of project is presented by

  1. A. Rates
  2. B. B.O.Q
  3. C. M.B
  4. D. Drawings
Answer: D. Drawings
