Q1. Which pricing model charges per second/hour with no long-term commitment?

  1. A. Reserved Instances
  2. B. On-Demand
  3. C. Spot only
  4. D. Savings Plans only
Answer: B. On-Demand

Q2. Spot Instances are:

  1. A. The most expensive
  2. B. Unused capacity sold at a discount, which can be interrupted
  3. C. Free forever
  4. D. For storage only
Answer: B. Unused capacity sold at a discount, which can be interrupted

Q3. AWS Free Tier allows:

  1. A. Unlimited usage
  2. B. Limited use of certain services free for a period/for new accounts
  3. C. Free support calls
  4. D. Free domains forever
Answer: B. Limited use of certain services free for a period/for new accounts

Q4. AWS Cost Explorer is used to:

  1. A. Write code
  2. B. Visualise and analyse AWS costs and usage
  3. C. Deploy servers
  4. D. Manage users
Answer: B. Visualise and analyse AWS costs and usage

Q5. Which support plan gives 24/7 access to Cloud Support Engineers?

  1. A. Basic
  2. B. Developer
  3. C. Business and Enterprise plans
  4. D. None
Answer: C. Business and Enterprise plans

Q6. AWS Trusted Advisor provides:

  1. A. Legal advice
  2. B. Recommendations on cost, security, performance and fault tolerance
  3. C. Loans
  4. D. Hardware
Answer: B. Recommendations on cost, security, performance and fault tolerance

Q7. Tags on AWS resources are mainly used to:

  1. A. Encrypt data
  2. B. Organise resources and track costs
  3. C. Speed up servers
  4. D. Block access
Answer: B. Organise resources and track costs

Q8. A consolidated bill in AWS Organizations gives:

  1. A. Separate bills per account
  2. B. One combined bill for all accounts
  3. C. No bill
  4. D. A bill in paper only
Answer: B. One combined bill for all accounts

Q9. Reserved Instances give a discount in exchange for:

  1. A. Paying nothing
  2. B. Committing to 1 or 3 years of usage
  3. C. Using more storage
  4. D. Sharing accounts
Answer: B. Committing to 1 or 3 years of usage

Q10. AWS Budgets lets you:

  1. A. Deploy code
  2. B. Set cost/usage budgets and get alerts when thresholds are approached
  3. C. Create users
  4. D. Buy hardware
Answer: B. Set cost/usage budgets and get alerts when thresholds are approached

Q11. How are customers charged when using AWS Lambda functions under serverless execution pricing?

  1. A. A flat monthly fee regardless of how many times the function is invoked
  2. B. Based on the number of execution requests and the duration it takes the code to run
  3. C. Based entirely on the physical size of the deployment package uploaded to S3
  4. D. A fixed hourly rate for every hour the function remains deployed in the region
Answer: B. Based on the number of execution requests and the duration it takes the code to run

Q12. When leveraging AWS Organizations, what advantage does linking multiple accounts provide regarding volume pricing?

  1. A. It limits overall data transfer speeds across all linked accounts for security purposes
  2. B. It combines resource usage across accounts to help reach higher tier volume discounts
  3. C. It completely eliminates all data egress charges between different AWS regions
  4. D. It automatically assigns identical IAM administrative policies to every sub-account
Answer: B. It combines resource usage across accounts to help reach higher tier volume discounts

Q13. Which billing term best describes the core payment model of AWS where customers only pay for the exact compute time, storage, and networking they consume without upfront commitments?

  1. A. Flat-rate subscription model
  2. B. Pay-as-you-go pricing model
  3. C. Pre-purchased resource licensing
  4. D. Enterprise software bundling
Answer: B. Pay-as-you-go pricing model

Q14. What is the primary purpose of the AWS Total Cost of Ownership (TCO) Calculator?

  1. A. To estimate financial savings when migrating from an on-premises datacenter to the AWS Cloud
  2. B. To automatically shut down idle compute resources at the end of each month
  3. C. To generate granular daily reports categorized by custom user tags
  4. D. To configure automated alerts whenever cloud spending exceeds a fixed threshold
Answer: A. To estimate financial savings when migrating from an on-premises datacenter to the AWS Cloud

Q15. Which AWS feature allows an organization to combine payments and track spending across multiple independent AWS accounts under a single master account?

  1. A. AWS Cost Explorer
  2. B. Consolidated Billing
  3. C. AWS Trusted Advisor
  4. D. Detailed Billing Report
Answer: B. Consolidated Billing

Q16. What factor primarily determines the hourly pricing structure for Amazon Elastic Block Store (EBS) volumes attached to EC2 instances?

  1. A. The total amount of inbound network traffic processed by the volume
  2. B. The physical geographic region where the volume is stored
  3. C. The provisioned storage capacity, volume type, and input/output performance characteristics
  4. D. The specific Linux or Windows operating system installed on the parent instance
Answer: C. The provisioned storage capacity, volume type, and input/output performance characteristics

Q17. Which AWS Support tier provides access to a dedicated Technical Account Manager (TAM)?

  1. A. Basic
  2. B. Developer
  3. C. Business
  4. D. Enterprise
Answer: D. Enterprise

Q18. What is the primary function of AWS Cost Allocation Tags?

  1. A. To restrict user access permissions
  2. B. To organize and track resource costs by project or department
  3. C. To automatically provision EC2 instances
  4. D. To encrypt data at rest
Answer: B. To organize and track resource costs by project or department

Q19. Which AWS tool enables you to visualize, understand, and manage your costs and usage over time up to the last 12 months?

  1. A. AWS Trusted Advisor
  2. B. AWS Cost Explorer
  3. C. AWS Budgets
  4. D. AWS Pricing Calculator
Answer: B. AWS Cost Explorer

Q20. Which AWS support plan offers the fastest response time of under 15 minutes for business-critical system down events?

  1. A. Developer
  2. B. Business
  3. C. Enterprise On-Ramp
  4. D. Enterprise
Answer: D. Enterprise

Q21. What feature of AWS Organizations allows you to centrally control permissions across multiple accounts using policies?

  1. A. Service Control Policies (SCPs)
  2. B. Access Control Lists (ACLs)
  3. C. Security Groups
  4. D. IAM Roles
Answer: A. Service Control Policies (SCPs)

Q22. Which AWS feature notifies you via email or SNS when your cost or usage exceeds defined custom thresholds?

  1. A. AWS Trusted Advisor
  2. B. AWS Budgets
  3. C. AWS Billing Conductor
  4. D. AWS CloudTrail
Answer: B. AWS Budgets

Q23. Which support tier provides a 30‑minute response time for high‑severity incidents and includes access to a dedicated Technical Account Manager?

  1. A. Basic
  2. B. Developer
  3. C. Business
  4. D. Enterprise
Answer: D. Enterprise

Q24. A startup wants a support plan that includes a 24‑hour response time for critical production incidents and access to a technical account manager. Which plan should they choose?

  1. A. Basic
  2. B. Developer
  3. C. Business
  4. D. Enterprise
Answer: D. Enterprise

Q25. If an organization wants to combine the billing of multiple AWS accounts into a single invoice, which feature should they enable?

  1. A. AWS Organizations Consolidated Billing
  2. B. AWS Savings Plans
  3. C. AWS Reserved Instances
  4. D. AWS Cost Explorer
Answer: A. AWS Organizations Consolidated Billing
