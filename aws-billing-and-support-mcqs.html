Q1. Which pricing model charges per second/hour with no long-term commitment?

  1. A. Reserved Instances
  2. B. On-Demand
  3. C. Spot only
  4. D. Savings Plans only
Answer: B. On-Demand

Q2. Spot Instances are:

  1. A. The most expensive
  2. B. Unused capacity sold at a discount, which can be interrupted
  3. C. Free forever
  4. D. For storage only
Answer: B. Unused capacity sold at a discount, which can be interrupted

Q3. AWS Free Tier allows:

  1. A. Unlimited usage
  2. B. Limited use of certain services free for a period/for new accounts
  3. C. Free support calls
  4. D. Free domains forever
Answer: B. Limited use of certain services free for a period/for new accounts

Q4. AWS Cost Explorer is used to:

  1. A. Write code
  2. B. Visualise and analyse AWS costs and usage
  3. C. Deploy servers
  4. D. Manage users
Answer: B. Visualise and analyse AWS costs and usage

Q5. Which support plan gives 24/7 access to Cloud Support Engineers?

  1. A. Basic
  2. B. Developer
  3. C. Business and Enterprise plans
  4. D. None
Answer: C. Business and Enterprise plans

Q6. AWS Trusted Advisor provides:

  1. A. Legal advice
  2. B. Recommendations on cost, security, performance and fault tolerance
  3. C. Loans
  4. D. Hardware
Answer: B. Recommendations on cost, security, performance and fault tolerance

Q7. Tags on AWS resources are mainly used to:

  1. A. Encrypt data
  2. B. Organise resources and track costs
  3. C. Speed up servers
  4. D. Block access
Answer: B. Organise resources and track costs

Q8. A consolidated bill in AWS Organizations gives:

  1. A. Separate bills per account
  2. B. One combined bill for all accounts
  3. C. No bill
  4. D. A bill in paper only
Answer: B. One combined bill for all accounts

Q9. Reserved Instances give a discount in exchange for:

  1. A. Paying nothing
  2. B. Committing to 1 or 3 years of usage
  3. C. Using more storage
  4. D. Sharing accounts
Answer: B. Committing to 1 or 3 years of usage

Q10. AWS Budgets lets you:

  1. A. Deploy code
  2. B. Set cost/usage budgets and get alerts when thresholds are approached
  3. C. Create users
  4. D. Buy hardware
Answer: B. Set cost/usage budgets and get alerts when thresholds are approached
