Q1. The first step of the nursing process is:

  1. A. Planning
  2. B. Assessment
  3. C. Evaluation
  4. D. Implementation
Answer: B. Assessment

Q2. Hand hygiene is most important because it:

  1. A. Saves time
  2. B. Prevents the spread of infection
  3. C. Is required by law only
  4. D. Keeps hands soft
Answer: B. Prevents the spread of infection

Q3. Normal adult oral body temperature is about:

  1. A. 35.0°C
  2. B. 37.0°C
  3. C. 38.5°C
  4. D. 40.0°C
Answer: B. 37.0°C

Q4. A patient's blood pressure of 120/80 mmHg is considered:

  1. A. Low
  2. B. Normal
  3. C. Stage 2 hypertension
  4. D. An emergency
Answer: B. Normal

Q5. When measuring respirations, the nurse should:

  1. A. Tell the patient to breathe deeply
  2. B. Count without making the patient aware
  3. C. Count for 5 seconds
  4. D. Ask the patient to count
Answer: B. Count without making the patient aware

Q6. The best site to check the pulse of an unconscious adult is:

  1. A. Radial
  2. B. Carotid
  3. C. Brachial
  4. D. Dorsal pedis
Answer: B. Carotid

Q7. Standard precautions apply to:

  1. A. Only infected patients
  2. B. All patients, all the time
  3. C. Only surgical patients
  4. D. Only children
Answer: B. All patients, all the time

Q8. A patient on bed rest is at risk of:

  1. A. Pressure injuries and blood clots
  2. B. Hearing loss
  3. C. Vision problems
  4. D. Allergies
Answer: A. Pressure injuries and blood clots

Q9. The correct order for donning PPE is:

  1. A. Gloves, gown, mask
  2. B. Gown, mask, goggles, gloves
  3. C. Mask, gloves, gown
  4. D. Any order is fine
Answer: B. Gown, mask, goggles, gloves

Q10. Documenting care should be done:

  1. A. At the end of the week
  2. B. As soon as possible after the care is given
  3. C. Only if there is a problem
  4. D. By the doctor
Answer: B. As soon as possible after the care is given
