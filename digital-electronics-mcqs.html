Q1. The binary number 1010 equals decimal:

  1. A. 12
  2. B. 6
  3. C. 10
  4. D. 8
Answer: C. 10

Q2. The output of an AND gate is high when:

  1. A. All inputs are high
  2. B. Inputs differ
  3. C. Any input is high
  4. D. All inputs are low
Answer: A. All inputs are high

Q3. The output of an OR gate is low only when:

  1. A. Inputs differ
  2. B. All inputs are high
  3. C. Any input is high
  4. D. All inputs are low
Answer: D. All inputs are low

Q4. A NOT gate is also called an:

  1. A. Adder
  2. B. Inverter
  3. C. Latch
  4. D. Buffer
Answer: B. Inverter

Q5. Which gate is called a universal gate?

  1. A. OR
  2. B. AND
  3. C. NAND
  4. D. XOR
Answer: C. NAND

Q6. A flip-flop stores:

  1. A. One bit
  2. B. Two bytes
  3. C. One word always
  4. D. One byte
Answer: A. One bit

Q7. The hexadecimal number system has base:

  1. A. 8
  2. B. 2
  3. C. 16
  4. D. 10
Answer: C. 16

Q8. A half adder adds:

  1. A. Eight bits
  2. B. Four bits
  3. C. Three bits
  4. D. Two bits
Answer: D. Two bits

Q9. A multiplexer selects:

  1. A. Two outputs
  2. B. One of several inputs
  3. C. All inputs
  4. D. No inputs
Answer: B. One of several inputs

Q10. A decoder converts:

  1. A. DC into AC
  2. B. Binary code into one-of-n output
  3. C. Light into sound
  4. D. Analog into digital
Answer: B. Binary code into one-of-n output

Q11. Which logic gate produces a low output only when all of its inputs are high?

  1. A. AND gate
  2. B. NAND gate
  3. C. NOR gate
  4. D. XOR gate
Answer: B. NAND gate

Q12. How many select lines are required for a multiplexer that has 16 data input lines?

  1. A. 2
  2. B. 3
  3. C. 4
  4. D. 5
Answer: C. 4

Q13. What is the primary function of a digital demultiplexer?

  1. A. Many inputs to one output
  2. B. One input to many outputs
  3. C. Converting binary to decimal
  4. D. Storing single bit data
Answer: B. One input to many outputs

Q14. Which sequential logic device changes its state on the triggering edge of a clock pulse and acts as a basic memory element?

  1. A. Logic Gate
  2. B. Flip-Flop
  3. C. Multiplexer
  4. D. Full Adder
Answer: B. Flip-Flop

Q15. In Boolean algebra, what is the simplification result of the expression A plus A inverted?

  1. A. 0
  2. B. 1
  3. C. A
  4. D. A inverted
Answer: B. 1

Q16. What arithmetic circuit is designed to add three single-bit binary numbers simultaneously?

  1. A. Half Adder
  2. B. Full Adder
  3. C. Half Subtractor
  4. D. Digital Comparator
Answer: B. Full Adder

Q17. The binary number 1101 is equal to which octal number?

  1. A. 13
  2. B. 15
  3. C. 17
  4. D. 21
Answer: A. 13

Q18. What is the decimal equivalent of the hexadecimal digit A?

  1. A. 9
  2. B. 10
  3. C. 11
  4. D. 12
Answer: B. 10

Q19. Which of the following items can exist in only two distinct states in a digital circuit?

  1. A. LED indicator
  2. B. Magnetic tape reel
  3. C. Punched card
  4. D. All of the above
Answer: D. All of the above

Q20. A standard 74‑series TTL NAND gate can safely drive how many other TTL gate inputs without signal degradation?

  1. A. 5
  2. B. 8
  3. C. 10
  4. D. 12
Answer: C. 10

Q21. Which logic gate can implement the Boolean function Y = A + B using only one gate?

  1. A. AND gate
  2. B. OR gate
  3. C. NAND gate
  4. D. XOR gate
Answer: B. OR gate

Q22. In a digital system, which bit is commonly added to a data word to help detect single‑bit errors?

  1. A. Checksum bit
  2. B. Parity bit
  3. C. Control bit
  4. D. Sync bit
Answer: B. Parity bit
