Control Systems MCQs (Electrical Engineering)

Q1. In an open-loop system the output:

  1. A. Affects the control action
  2. B. Does not affect the control action
  3. C. Is always stable
  4. D. Is zero
Answer: B. Does not affect the control action

Q2. Negative feedback generally:

  1. A. Doubles gain
  2. B. Removes the input
  3. C. Improves stability
  4. D. Causes instability
Answer: C. Improves stability

Q3. A transfer function is the ratio of output to input in the:

  1. A. Laplace domain
  2. B. Frequency of noise
  3. C. Time domain only
  4. D. Power domain
Answer: A. Laplace domain

Q4. A PID controller includes proportional, integral and:

  1. A. Digital actions
  2. B. Derivative actions
  3. C. Dynamic actions
  4. D. Differential gain only
Answer: B. Derivative actions

Q5. The steady-state error of a stable system is the error as time tends to:

  1. A. One
  2. B. Ten
  3. C. Zero
  4. D. Infinity
Answer: D. Infinity

Q6. Poles in the left half of the s-plane indicate:

  1. A. No response
  2. B. Oscillation only
  3. C. Instability
  4. D. Stability
Answer: D. Stability

Q7. The Nyquist criterion is used to test:

  1. A. Cost
  2. B. Weight
  3. C. Noise
  4. D. Stability
Answer: D. Stability

Q8. The settling time is the time to reach and stay within a band of the:

  1. A. Peak value
  2. B. Final value
  3. C. Zero value
  4. D. Initial value
Answer: B. Final value

Q9. A servo mechanism is a:

  1. A. Transformer
  2. B. Power plant
  3. C. Non-feedback system
  4. D. Feedback control system for position
Answer: D. Feedback control system for position

Q10. Gain margin is a measure of:

  1. A. Weight
  2. B. Heat
  3. C. Relative stability
  4. D. Cost
Answer: C. Relative stability

Q11. Which of the following is a primary benefit of using a closed‑loop control system in industrial automation?

  1. A. Higher power consumption
  2. B. Reduced sensitivity to load changes
  3. C. Simpler controller design
  4. D. No need for sensors
Answer: B. Reduced sensitivity to load changes

Q12. If a second‑order system has an overshoot of 30%, what is its approximate damping ratio?

  1. A. 0.10
  2. B. 0.30
  3. C. 0.50
  4. D. 0.70
Answer: C. 0.50

Q13. Which component is NOT typically found in a conventional automatic control loop?

  1. A. Controller
  2. B. Sensor
  3. C. Actuator
  4. D. Power supply
Answer: D. Power supply

Q14. A test signal used to evaluate a system’s frequency response should have which characteristic?

  1. A. A single frequency tone
  2. B. A constant amplitude step
  3. C. A random noise burst
  4. D. A sinusoid sweeping through frequencies
Answer: D. A sinusoid sweeping through frequencies

Q15. For a minimum‑phase system, which statement about its poles and zeros is true?

  1. A. All zeros lie in the right half‑plane
  2. B. All poles lie in the left half‑plane
  3. C. Poles and zeros can be anywhere
  4. D. Zeros must be on the imaginary axis
Answer: B. All poles lie in the left half‑plane

Q16. The transfer function of a system with positive feedback is given by H(s) = G(s) / (1 - G(s)H(s)). What does the denominator represent?

  1. A. Open‑loop gain
  2. B. Closed‑loop characteristic equation
  3. C. Feedback factor
  4. D. Sensor gain
Answer: B. Closed‑loop characteristic equation
