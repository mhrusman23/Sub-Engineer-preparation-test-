Q1. In an open-loop system the output:

  1. A. Affects the control action
  2. B. Does not affect the control action
  3. C. Is always stable
  4. D. Is zero
Answer: B. Does not affect the control action

Q2. Negative feedback generally:

  1. A. Doubles gain
  2. B. Removes the input
  3. C. Improves stability
  4. D. Causes instability
Answer: C. Improves stability

Q3. A transfer function is the ratio of output to input in the:

  1. A. Laplace domain
  2. B. Frequency of noise
  3. C. Time domain only
  4. D. Power domain
Answer: A. Laplace domain

Q4. A PID controller includes proportional, integral and:

  1. A. Digital actions
  2. B. Derivative actions
  3. C. Dynamic actions
  4. D. Differential gain only
Answer: B. Derivative actions

Q5. The steady-state error of a stable system is the error as time tends to:

  1. A. One
  2. B. Ten
  3. C. Zero
  4. D. Infinity
Answer: D. Infinity

Q6. Poles in the left half of the s-plane indicate:

  1. A. No response
  2. B. Oscillation only
  3. C. Instability
  4. D. Stability
Answer: D. Stability

Q7. The Nyquist criterion is used to test:

  1. A. Cost
  2. B. Weight
  3. C. Noise
  4. D. Stability
Answer: D. Stability

Q8. The settling time is the time to reach and stay within a band of the:

  1. A. Peak value
  2. B. Final value
  3. C. Zero value
  4. D. Initial value
Answer: B. Final value

Q9. A servo mechanism is a:

  1. A. Transformer
  2. B. Power plant
  3. C. Non-feedback system
  4. D. Feedback control system for position
Answer: D. Feedback control system for position

Q10. Gain margin is a measure of:

  1. A. Weight
  2. B. Heat
  3. C. Relative stability
  4. D. Cost
Answer: C. Relative stability

Q11. Which of the following is a primary benefit of using a closed‑loop control system in industrial automation?

  1. A. Higher power consumption
  2. B. Reduced sensitivity to load changes
  3. C. Simpler controller design
  4. D. No need for sensors
Answer: B. Reduced sensitivity to load changes

Q12. If a second‑order system has an overshoot of 30%, what is its approximate damping ratio?

  1. A. 0.10
  2. B. 0.30
  3. C. 0.50
  4. D. 0.70
Answer: C. 0.50

Q13. Which component is NOT typically found in a conventional automatic control loop?

  1. A. Controller
  2. B. Sensor
  3. C. Actuator
  4. D. Power supply
Answer: D. Power supply

Q14. A test signal used to evaluate a system’s frequency response should have which characteristic?

  1. A. A single frequency tone
  2. B. A constant amplitude step
  3. C. A random noise burst
  4. D. A sinusoid sweeping through frequencies
Answer: D. A sinusoid sweeping through frequencies

Q15. For a minimum‑phase system, which statement about its poles and zeros is true?

  1. A. All zeros lie in the right half‑plane
  2. B. All poles lie in the left half‑plane
  3. C. Poles and zeros can be anywhere
  4. D. Zeros must be on the imaginary axis
Answer: B. All poles lie in the left half‑plane

Q16. The transfer function of a system with positive feedback is given by H(s) = G(s) / (1 - G(s)H(s)). What does the denominator represent?

  1. A. Open‑loop gain
  2. B. Closed‑loop characteristic equation
  3. C. Feedback factor
  4. D. Sensor gain
Answer: B. Closed‑loop characteristic equation

Q17. Which mathematical transformation is predominantly used to analyze discrete-time control systems?

  1. A. Laplace transform
  2. B. Fourier transform
  3. C. Z-transform
  4. D. Hilbert transform
Answer: C. Z-transform

Q18. In a Bode plot, the phase margin of a system indicates its degree of:

  1. A. Power efficiency
  2. B. Relative stability
  3. C. Operating bandwidth
  4. D. DC gain magnitude
Answer: B. Relative stability

Q19. What effect does adding a pole to the open-loop transfer function have on the root locus of a control system?

  1. A. Pulls the root locus towards the right-half s-plane
  2. B. Pulls the root locus towards the left-half s-plane
  3. C. Has no effect on system trajectories
  4. D. Rotates the asymptotes by 180 degrees
Answer: A. Pulls the root locus towards the right-half s-plane

Q20. Which of the following controllers eliminates steady-state error completely by accumulating the error over time?

  1. A. Derivative controller
  2. B. Proportional controller
  3. C. Integral controller
  4. D. On-Off controller
Answer: C. Integral controller

Q21. What is the primary advantage of incorporating tachometer feedback in a DC servo motor control system?

  1. A. Increases output power
  2. B. Provides damping to improve transient response
  3. C. Eliminates static friction completely
  4. D. Reduces the supply voltage requirement
Answer: B. Provides damping to improve transient response

Q22. For a second-order underdamped control system, the peak overshoot is determined primarily by the:

  1. A. Damping ratio
  2. B. Natural frequency
  3. C. DC gain
  4. D. Time constant
Answer: A. Damping ratio

Q23. Which of the following performance metrics is generally improved and expanded when a derivative component is added to a controller?

  1. A. Bandwidth
  2. B. Steady-state error
  3. C. High-frequency noise rejection
  4. D. Phase lag
Answer: A. Bandwidth

Q24. A control system operating in an environment characterized by unpredictable external disturbances is designated as a:

  1. A. Adaptive control system
  2. B. Stochastic control system
  3. C. Digital data system
  4. D. Computer control system
Answer: B. Stochastic control system

Q25. Within a standard feedback control loop, the calculated output signal generated by the controller is directly fed into the:

  1. A. Final control element
  2. B. Amplifier
  3. C. Comparator
  4. D. Sensor
Answer: A. Final control element
