IELTS Task 1 Charts MCQs (IELTS & English Tests)

Q1. In Task 1, the overview paragraph should:

  1. A. Give your opinion
  2. B. Summarise the main trends and big picture
  3. C. List every number
  4. D. Be the longest paragraph
Answer: B. Summarise the main trends and big picture

Q2. Which phrase describes an increase?

  1. A. Dropped sharply
  2. B. Rose gradually
  3. C. Remained stable
  4. D. Fell slightly
Answer: B. Rose gradually

Q3. 'Sales fluctuated' means sales:

  1. A. Only increased
  2. B. Went up and down irregularly
  3. C. Stayed flat
  4. D. Stopped
Answer: B. Went up and down irregularly

Q4. A 'peak' in a graph is:

  1. A. The lowest point
  2. B. The highest point
  3. C. The average
  4. D. The start
Answer: B. The highest point

Q5. Which word means 'stayed the same'?

  1. A. Soared
  2. B. Levelled off
  3. C. Plunged
  4. D. Doubled
Answer: B. Levelled off

Q6. In a pie chart, figures are usually shown as:

  1. A. Distances
  2. B. Percentages or proportions
  3. C. Temperatures
  4. D. Dates
Answer: B. Percentages or proportions

Q7. For a process diagram, the best structure is:

  1. A. Opinion paragraphs
  2. B. Stages in order, mostly passive voice
  3. C. A debate
  4. D. A story
Answer: B. Stages in order, mostly passive voice

Q8. 'Respectively' is used to:

  1. A. Show contrast
  2. B. Link two lists in the same order
  3. C. Give an opinion
  4. D. End the answer
Answer: B. Link two lists in the same order

Q9. Which is a good paraphrase of 'the number of cars sold'?

  1. A. Car sales figures
  2. B. Cars were solding
  3. C. The sold cars number
  4. D. Selling of car
Answer: A. Car sales figures

Q10. Data should be grouped in Task 1 by:

  1. A. Random order
  2. B. Logical categories such as high/low or similar trends
  3. C. Alphabet
  4. D. Colour
Answer: B. Logical categories such as high/low or similar trends

Q11. 'A dramatic rise' means:

  1. A. A tiny rise
  2. B. A very large, sudden rise
  3. C. No rise
  4. D. A fall
Answer: B. A very large, sudden rise

Q12. In a table task, you should mainly:

  1. A. Copy the whole table in words
  2. B. Select and compare the most significant data
  3. C. Ignore small numbers completely
  4. D. Add your own data
Answer: B. Select and compare the most significant data

Q13. The past tense is needed in Task 1 when:

  1. A. The chart shows future plans
  2. B. The chart shows past years
  3. C. Always
  4. D. Never
Answer: B. The chart shows past years

Q14. 'Accounted for 20%' means:

  1. A. Counted 20 people
  2. B. Made up 20% of the total
  3. C. Increased by 20
  4. D. Cost 20 dollars
Answer: B. Made up 20% of the total

Q15. A good Task 1 answer has how many main parts?

  1. A. One
  2. B. Introduction, overview, and detail paragraphs
  3. C. Only a conclusion
  4. D. Five essays
Answer: B. Introduction, overview, and detail paragraphs

Q16. Which phrase shows a small decrease?

  1. A. Plummeted
  2. B. Dipped slightly
  3. C. Skyrocketed
  4. D. Remained constant
Answer: B. Dipped slightly

Q17. For maps (before/after), the focus should be on:

  1. A. Your opinion of the town
  2. B. The main changes between the two maps
  3. C. Every small building
  4. D. The weather
Answer: B. The main changes between the two maps

Q18. 'Overtook' in a graph description means:

  1. A. Fell behind
  2. B. Passed and became higher than
  3. C. Stayed equal
  4. D. Disappeared
Answer: B. Passed and became higher than

Q19. Comparative language in Task 1 is used to:

  1. A. Tell a story
  2. B. Compare data between categories
  3. C. Ask questions
  4. D. Give advice
Answer: B. Compare data between categories

Q20. The overview should be placed:

  1. A. At the very end only
  2. B. After the introduction, before details
  3. C. In the middle of details
  4. D. It is not needed
Answer: B. After the introduction, before details
