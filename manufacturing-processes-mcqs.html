Q1. Which process joins metals by melting and fusion?

  1. A. Casting
  2. B. Forging
  3. C. Machining
  4. D. Welding
Answer: D. Welding

Q2. Pouring molten metal into a mould is:

  1. A. Drawing
  2. B. Forging
  3. C. Rolling
  4. D. Casting
Answer: D. Casting

Q3. A lathe is mainly used for:

  1. A. Drilling only
  2. B. Grinding gears only
  3. C. Turning
  4. D. Milling flat surfaces
Answer: C. Turning

Q4. Heating metal and shaping by hammering is:

  1. A. Extrusion
  2. B. Sintering
  3. C. Forging
  4. D. Casting
Answer: C. Forging

Q5. The process of making holes is:

  1. A. Turning
  2. B. Rolling
  3. C. Drilling
  4. D. Shaping
Answer: C. Drilling

Q6. Which machine tool uses a multi-point rotating cutter?

  1. A. Lathe
  2. B. Press
  3. C. Shaper
  4. D. Milling machine
Answer: D. Milling machine

Q7. A shaper is mainly used for producing:

  1. A. Threads only
  2. B. Gears only
  3. C. Round holes
  4. D. Flat surfaces
Answer: D. Flat surfaces

Q8. Heat treatment that softens metal is:

  1. A. Quenching
  2. B. Annealing
  3. C. Case hardening
  4. D. Hardening
Answer: B. Annealing

Q9. Powder metallurgy uses:

  1. A. Hot rolling
  2. B. Molten metal poured
  3. C. Metal powders pressed and sintered
  4. D. Machining only
Answer: C. Metal powders pressed and sintered

Q10. CNC stands for computer numerical:

  1. A. Cutting
  2. B. Code
  3. C. Circuit
  4. D. Control
Answer: D. Control

Q11. Which specific manufacturing method forces heated plastic material through a shaped die to form continuous profiles?

  1. A. Injection molding
  2. B. Extrusion
  3. C. Blow molding
  4. D. Thermoforming
Answer: B. Extrusion

Q12. In standard gas welding operations, what type of flame is generally preferred for welding most common steels to prevent metal oxidation?

  1. A. Carburizing flame
  2. B. Neutral flame
  3. C. Oxidizing flame
  4. D. Reducing flame
Answer: B. Neutral flame

Q13. Which machining parameter exerts the most dominant influence on the rate of tool wear during turning operations?

  1. A. Depth of cut
  2. B. Feed rate
  3. C. Cutting speed
  4. D. Workpiece diameter
Answer: C. Cutting speed

Q14. What is the primary technical objective of the subcritical annealing or process annealing heat treatment process?

  1. A. Maximum hardness
  2. B. Internal stress relief and restored ductility
  3. C. Grain coarsening
  4. D. High tensile strength
Answer: B. Internal stress relief and restored ductility

Q15. Which non-traditional machining process relies primarily on thermal erosion via continuous electrical spark discharges?

  1. A. Ultrasonic machining
  2. B. Abrasive jet machining
  3. C. Electrical discharge machining
  4. D. Electrochemical machining
Answer: C. Electrical discharge machining

Q16. What is the fundamental initial step in the complete powder metallurgy production cycle before sintering?

  1. A. Compaction
  2. B. Atomization
  3. C. Sintering
  4. D. Infiltration
Answer: A. Compaction

Q17. In a G-code programming block, what does the command code G02 specifically instruct the CNC machine to perform?

  1. A. Linear interpolation at rapid feed
  2. B. Circular interpolation in a clockwise direction
  3. C. Incremental dimension programming mode
  4. D. Canned drilling cycle execution
Answer: B. Circular interpolation in a clockwise direction

Q18. Which type of tool rest is specifically designed to support an exceptionally flexible workpiece very close to the active cutting edge on a lathe?

  1. A. Steady rest
  2. B. Compound rest
  3. C. Follower rest
  4. D. Tool post
Answer: C. Follower rest

Q19. Ceramic cutting tool inserts are primarily manufactured from which of the following materials?

  1. A. Tungsten carbide
  2. B. Aluminum oxide
  3. C. High-speed steel
  4. D. Silicon nitride
Answer: B. Aluminum oxide

Q20. In a standard gas welding setup, the color typically used to paint the acetylene cylinder is:

  1. A. Black
  2. B. Maroon
  3. C. Blue
  4. D. White
Answer: B. Maroon

Q21. Tool steel alloy properties, particularly wear resistance and toughness, are significantly enhanced when alloyed with chromium and:

  1. A. Vanadium
  2. B. Copper
  3. C. Lead
  4. D. Zinc
Answer: A. Vanadium

Q22. When performing a reaming operation inside a blind hole, which specific tool design is best suited to effectively bridge interruptions?

  1. A. Left-hand spiral flute reamer
  2. B. Straight flute reamer
  3. C. Right-hand spiral flute reamer
  4. D. Parallel shank stub reamer
Answer: C. Right-hand spiral flute reamer

Q23. Which cutting parameter has the most predominant effect on raising the cutting temperature during machining?

  1. A. Depth of cut
  2. B. Cutting speed
  3. C. Feed rate
  4. D. Tool rake angle
Answer: B. Cutting speed

Q24. What is the primary manufacturing method utilized for producing long thin wires in mass production?

  1. A. Extrusion
  2. B. Rolling
  3. C. Drawing
  4. D. Swaging
Answer: C. Drawing

Q25. During a metal cutting process, the vast majority of the total heat generated is concentrated in which region?

  1. A. The tool shank
  2. B. The shear zone
  3. C. The machine bed
  4. D. The clamping fixture
Answer: B. The shear zone
