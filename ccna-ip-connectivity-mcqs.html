Q1. A default route is used when:

  1. A. The destination is local
  2. B. There is no specific route to the destination network
  3. C. The link is down
  4. D. Always
Answer: B. There is no specific route to the destination network

Q2. OSPF is:

  1. A. An application protocol
  2. B. A link-state routing protocol
  3. C. A cable type
  4. D. A security tool
Answer: B. A link-state routing protocol

Q3. The administrative distance of a directly connected route is:

  1. A. 0
  2. B. 1
  3. C. 90
  4. D. 110
Answer: A. 0

Q4. Static routing is best suited for:

  1. A. Very large networks
  2. B. Small networks and stub networks
  3. C. The whole internet
  4. D. Wireless only
Answer: B. Small networks and stub networks

Q5. A routing loop causes packets to:

  1. A. Arrive faster
  2. B. Circle endlessly until TTL expires
  3. C. Be encrypted
  4. D. Be stored
Answer: B. Circle endlessly until TTL expires

Q6. IPv6 addresses are:

  1. A. 32-bit
  2. B. 64-bit
  3. C. 128-bit
  4. D. 256-bit
Answer: C. 128-bit

Q7. The command 'show ip route' displays:

  1. A. Users
  2. B. The routing table
  3. C. Passwords
  4. D. Interfaces only
Answer: B. The routing table

Q8. First-hop redundancy protocols like HSRP provide:

  1. A. Faster cables
  2. B. A backup gateway if the main router fails
  3. C. More bandwidth
  4. D. Encryption
Answer: B. A backup gateway if the main router fails

Q9. NAT is used to:

  1. A. Translate private IP addresses to public ones
  2. B. Speed up CPUs
  3. C. Store backups
  4. D. Block all traffic
Answer: A. Translate private IP addresses to public ones

Q10. A floating static route is used as:

  1. A. The main route
  2. B. A backup route with a higher administrative distance
  3. C. A wireless route
  4. D. A test route
Answer: B. A backup route with a higher administrative distance

Q11. Which specific protocol operates inside the network layer to map a known layer 3 IP address to a hardware layer 2 MAC address?

  1. A. A) ICMP
  2. B. B) ARP
  3. C. C) SNMP
  4. D. D) DHCP
Answer: B. B) ARP

Q12. Which routing protocol algorithm classification does Open Shortest Path First (OSPF) belong to?

  1. A. A) Distance-vector protocol
  2. B. B) Link-state routing protocol
  3. C. C) Path-vector protocol
  4. D. D) Hybrid routing protocol
Answer: B. B) Link-state routing protocol

Q13. What is the default Administrative Distance (AD) assigned to an OSPF routing protocol entry?

  1. A. A) 90
  2. B. B) 110
  3. C. C) 120
  4. D. D) 100
Answer: B. B) 110

Q14. What type of IP communication method delivers a single data stream from one source to a defined group of multiple destination nodes?

  1. A. A) Unicast
  2. B. B) Broadcast
  3. C. C) Multicast
  4. D. D) Anycast
Answer: C. C) Multicast

Q15. How many usable host IP addresses are available within a single subnet configured with a /26 prefix length?

  1. A. A) 32
  2. B. B) 62
  3. C. C) 64
  4. D. D) 126
Answer: B. B) 62

Q16. Which administrative routing mechanism involves manually configuring routes without using dynamic updates?

  1. A. A) Dynamic routing
  2. B. B) Static routing
  3. C. C) Policy-based routing
  4. D. D) Default bridging
Answer: B. B) Static routing

Q17. What is the primary function of Administrative Distance (AD) in a Cisco router?

  1. A. To measure the link speed of a path
  2. B. To select the best path when multiple routing protocols learn the same route
  3. C. To determine the physical port speed
  4. D. To encrypt packets between routers
Answer: B. To select the best path when multiple routing protocols learn the same route

Q18. When a router has learned about a destination network through multiple sources, which Administrative Distance value will it trust the most?

  1. A. 110
  2. B. 120
  3. C. 90
  4. D. 255
Answer: C. 90

Q19. What routing principle does a router use to select the most specific route available in its routing table?

  1. A. Longest Prefix Match
  2. B. Shortest Path First
  3. C. Lowest Hop Count
  4. D. Highest Bandwidth Allocation
Answer: A. Longest Prefix Match

Q20. Which routing protocol type uses Dijkstra's algorithm to build a complete topology map of the network?

  1. A. Distance Vector
  2. B. Path Vector
  3. C. Link-State
  4. D. Static
Answer: C. Link-State

Q21. Which command configures an IPv6 address using an automatically generated interface ID based on the MAC address?

  1. A. ipv6 address dhcp
  2. B. ipv6 address autoconfig
  3. C. ipv6 address eui-64
  4. D. ipv6 address slaac
Answer: C. ipv6 address eui-64

Q22. How many usable host IP addresses are available in a subnet with a /26 prefix?

  1. A. 30
  2. B. 62
  3. C. 64
  4. D. 128
Answer: B. 62

Q23. Which specific command is utilized to configure an IPv6 static default route on a Cisco IOS router?

  1. A. ipv6 route ::/0 interface next-hop
  2. B. ipv6 route default interface next-hop
  3. C. ipv6 route 0.0.0.0/0 interface next-hop
  4. D. ip route 0.0.0.0/0 interface next-hop
Answer: A. ipv6 route ::/0 interface next-hop

Q24. Which network communication type specifically establishes a one-to-many or one-to-group relationship?

  1. A. Unicast
  2. B. Multicast
  3. C. Broadcast
  4. D. Loopback
Answer: B. Multicast

Q25. Which networking term defines a one-to-one communication stream between a single sender and a single receiver?

  1. A. Broadcast
  2. B. Multicast
  3. C. Unicast
  4. D. Anycast
Answer: C. Unicast
