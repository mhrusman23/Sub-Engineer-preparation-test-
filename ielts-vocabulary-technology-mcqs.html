Q1. To 'browse' the internet means to:

  1. A. Buy things
  2. B. Look through websites casually
  3. C. Hack computers
  4. D. Write code
Answer: B. Look through websites casually

Q2. A 'gadget' is:

  1. A. A large machine
  2. B. A small, clever electronic device
  3. C. A website
  4. D. A password
Answer: B. A small, clever electronic device

Q3. 'Outdated' technology is:

  1. A. Very new
  2. B. Old and no longer useful or modern
  3. C. Expensive
  4. D. Broken
Answer: B. Old and no longer useful or modern

Q4. To 'upgrade' your phone means to:

  1. A. Break it
  2. B. Get a newer or better version
  3. C. Charge it
  4. D. Sell it
Answer: B. Get a newer or better version

Q5. 'Artificial intelligence' (AI) refers to:

  1. A. Human memory
  2. B. Computer systems that can perform tasks needing human intelligence
  3. C. Robots only
  4. D. The internet
Answer: B. Computer systems that can perform tasks needing human intelligence

Q6. A 'breach' of data means:

  1. A. Safe storage
  2. B. Unauthorised access to private information
  3. C. Faster internet
  4. D. A backup
Answer: B. Unauthorised access to private information

Q7. To 'stream' a video means to:

  1. A. Download it fully first
  2. B. Watch it online as it loads
  3. C. Record it
  4. D. Delete it
Answer: B. Watch it online as it loads

Q8. 'Wireless' devices connect:

  1. A. With many cables
  2. B. Without cables, using radio signals
  3. C. Only by wire
  4. D. By post
Answer: B. Without cables, using radio signals

Q9. A 'user-friendly' app is:

  1. A. Hard to use
  2. B. Easy for people to use
  3. C. Only for experts
  4. D. Free of charge
Answer: B. Easy for people to use

Q10. 'Cutting-edge' technology is:

  1. A. Dangerous
  2. B. The most advanced and modern
  3. C. Very old
  4. D. Cheap
Answer: B. The most advanced and modern

Q11. To 'back up' your files means to:

  1. A. Delete them
  2. B. Make a copy in case the original is lost
  3. C. Share them publicly
  4. D. Rename them
Answer: B. Make a copy in case the original is lost

Q12. 'Social media' includes platforms like:

  1. A. Word processors
  2. B. Facebook, Instagram and TikTok
  3. C. Calculators
  4. D. Printers
Answer: B. Facebook, Instagram and TikTok

Q13. A 'virus' in computing is:

  1. A. A medicine
  2. B. Harmful software that spreads and damages systems
  3. C. A keyboard
  4. D. An update
Answer: B. Harmful software that spreads and damages systems

Q14. 'Automation' means using machines or computers to:

  1. A. Do work automatically with little human help
  2. B. Slow work down
  3. C. Hire more people
  4. D. Print documents
Answer: A. Do work automatically with little human help

Q15. To 'install' an app means to:

  1. A. Delete it
  2. B. Put it on your device so it can be used
  3. C. Rate it
  4. D. Share it
Answer: B. Put it on your device so it can be used

Q16. 'Bandwidth' affects:

  1. A. Screen size
  2. B. How much data can be transferred — internet speed capacity
  3. C. Battery colour
  4. D. Sound only
Answer: B. How much data can be transferred — internet speed capacity

Q17. A 'notification' on your phone is:

  1. A. A virus
  2. B. A message alert from an app
  3. C. A charger
  4. D. A wallpaper
Answer: B. A message alert from an app

Q18. 'E-commerce' means:

  1. A. Email writing
  2. B. Buying and selling goods online
  3. C. Online gaming
  4. D. Video calls
Answer: B. Buying and selling goods online

Q19. To 'log in' means to:

  1. A. Turn off the device
  2. B. Enter your details to access an account
  3. C. Create a virus
  4. D. Print a page
Answer: B. Enter your details to access an account

Q20. 'Virtual reality' (VR) creates:

  1. A. Real places
  2. B. A computer-generated world you can experience with a headset
  3. C. Faster Wi-Fi
  4. D. New phones
Answer: B. A computer-generated world you can experience with a headset
