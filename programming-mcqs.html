Q1. Which keyword is used to define a function in Python?

  1. A. func
  2. B. define
  3. C. def
  4. D. function
Answer: C. def

Q2. What is the output of 2 ** 3 in Python?

  1. A. 8
  2. B. 5
  3. C. 9
  4. D. 6
Answer: A. 8

Q3. Which loop runs at least once, even if the condition is false?

  1. A. for
  2. B. foreach
  3. C. do-while
  4. D. while
Answer: C. do-while

Q4. In most languages, an array index normally starts at:

  1. A. 0
  2. B. 1
  3. C. 2
  4. D. -1
Answer: A. 0

Q5. Which symbol is used for a single-line comment in C++?

  1. A. <!-- -->
  2. B. #
  3. C. --
  4. D. //
Answer: D. //

Q6. A variable that stores true or false is of type:

  1. A. Integer
  2. B. String
  3. C. Boolean
  4. D. Float
Answer: C. Boolean

Q7. Which statement is used to exit a loop immediately?

  1. A. break
  2. B. continue
  3. C. return only
  4. D. skip
Answer: A. break

Q8. Recursion means a function:

  1. A. Calls itself
  2. B. Runs in parallel always
  3. C. Never returns
  4. D. Calls only main
Answer: A. Calls itself

Q9. Which of the following is an object-oriented programming concept?

  1. A. Compilation
  2. B. Linking
  3. C. Debugging
  4. D. Inheritance
Answer: D. Inheritance

Q10. In Java, which keyword creates a new object?

  1. A. create
  2. B. object
  3. C. make
  4. D. new
Answer: D. new

Q11. In object-oriented programming, what mechanism allows a class to inherit properties from multiple parent classes?

  1. A. Encapsulation
  2. B. Polymorphism
  3. C. Multiple Inheritance
  4. D. Abstraction
Answer: C. Multiple Inheritance

Q12. In Object-Oriented Programming, the ability of a variable to take many forms is known as:

  1. A. Encapsulation
  2. B. Inheritance
  3. C. Polymorphism
  4. D. Abstraction
Answer: C. Polymorphism

Q13. What is the primary role of a conditional statement in a program?

  1. A. To repeat a block of code a fixed number of times
  2. B. To allocate memory dynamically
  3. C. To choose between alternative blocks of code
  4. D. To define a new data type
Answer: C. To choose between alternative blocks of code

Q14. Which loop construct guarantees that the loop body executes at least once, regardless of the initial condition?

  1. A. for loop
  2. B. while loop
  3. C. do‑while loop
  4. D. foreach loop
Answer: C. do‑while loop

Q15. If a pointer `int *ptr` points to memory address 2000, what address will `ptr + 3` refer to?

  1. A. 2003
  2. B. 2009
  3. C. 2012
  4. D. 2006
Answer: C. 2012

Q16. Which keyword should be used to release memory that was allocated with the `new` operator in C++?

  1. A. free
  2. B. delete
  3. C. release
  4. D. dispose
Answer: B. delete

Q17. Which of the following is NOT a typical debugging technique used during software development?

  1. A. Using breakpoints to pause execution
  2. B. Logging variable values at runtime
  3. C. Refactoring the entire codebase
  4. D. Step‑by‑step execution
Answer: C. Refactoring the entire codebase

Q18. In which programming language is function overloading explicitly not supported?

  1. A. Java
  2. B. C++
  3. C. C
  4. D. Python
Answer: C. C
