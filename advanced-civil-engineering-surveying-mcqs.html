Q1. The function of theodolite is to measure.

  1. A. Horizontal angle
  2. B. Vertical angle
  3. C. Deflection angle
  4. D. All of these
Answer: D. All of these

Q2. Method of ensuring the inter-visibility of two survey stations:

  1. A. Similar chords
  2. B. Similar triangles
  3. C. Tangent line
  4. D. All of these
Answer: B. Similar triangles

Q3. Radius of one degree curve is:

  1. A. 100 m
  2. B. 1720 m
  3. C. 1000 m
  4. D. 1500 m
Answer: B. 1720 m

Q4. Marking on ground for excavation according to plan of the structure is termed.

  1. A. Layout
  2. B. Setting out
  3. C. Marking
  4. D. Alignment
Answer: A. Layout

Q5. Coordinates of a point are measured with:

  1. A. level
  2. B. theodolite
  3. C. Distance meter
  4. D. total station
Answer: D. total station

Q6. GPS means.

  1. A. Geo positioning system
  2. B. Global positioning system
  3. C. Geographical positioning system
  4. D. Great positioning system
Answer: B. Global positioning system

Q7. A type of survey in which data is collected from a far distance.

  1. A. Remote sensing
  2. B. Theodolite survey
  3. C. Trigonometric survey
  4. D. All of these
Answer: A. Remote sensing

Q8. GIS stands for

  1. A. Geo-logical Institute for studies
  2. B. Geographical inside science
  3. C. Geo-Technical Infra structure
  4. D. Geographic information system
Answer: D. Geographic information system

Q9. The theodolite whose telescope can rotate through complete revolution in vertical plane is called:

  1. A. Transit
  2. B. Tilting
  3. C. Non-transit
  4. D. All of these
Answer: A. Transit

Q10. In well conditioned triangle no angle should be less than:

  1. A. 45°
  2. B. 60°
  3. C. 70°
  4. D. 30°
Answer: D. 30°

Q11. A radius of 3 degree curve in feet.

  1. A. 1702
  2. B. 1910
  3. C. 1720
  4. D. 1857
Answer: B. 1910

Q12. Driving pegs at the corners of plan of a structure on the ground is termed.

  1. A. Layout
  2. B. Marking
  3. C. Alignment
  4. D. Setting out
Answer: D. Setting out

Q13. Total station can measure:

  1. A. angles
  2. B. distances
  3. C. both of these
  4. D. All of these
Answer: C. both of these

Q14. Global positioning system (G.P.S) work with the help of,

  1. A. Total Station
  2. B. Internet
  3. C. Satellites
  4. D. Magnet
Answer: C. Satellites

Q15. During airborne imagery photo is taken from.

  1. A. Target
  2. B. Drone
  3. C. Satellite
  4. D. All of these
Answer: B. Drone

Q16. GIS controls the following field.

  1. A. Urban planning
  2. B. Flood forecasting
  3. C. Transportation planning
  4. D. All of these
Answer: D. All of these

Q17. The size of theodolite is expressed by

  1. A. Magnifying power
  2. B. Dia of main scale
  3. C. Weight of theodolite
  4. D. Length of telescope
Answer: B. Dia of main scale

Q18. Maximum angle in well-conditioned triangle is:

  1. A. 180°
  2. B. 30°
  3. C. 120°
  4. D. 130°
Answer: C. 120°

Q19. The relation between radius (R) and degree (D) of a curve is;

  1. A. R = 1720/D
  2. B. R = 1750/D
  3. C. R/D = 1720
  4. D. R = D/1720
Answer: A. R = 1720/D

Q20. Small temporary wall or fixing board in front of walls for guidance during setting out for any structure is called.

  1. A. Toe-wall
  2. B. Dwarf wall
  3. C. Profile
  4. D. Sign Board
Answer: C. Profile

Q21. Total station is such type of theodolite:

  1. A. digital
  2. B. computerized
  3. C. electronic
  4. D. all of these
Answer: D. all of these

Q22. True bearing is observed with,

  1. A. Total Station
  2. B. Prismatic Compass
  3. C. G.P.S
  4. D. Theodolite
Answer: C. G.P.S

Q23. Component of remote sensing is.

  1. A. Energy source
  2. B. Interaction with target
  3. C. Recording of energy
  4. D. All of these
Answer: D. All of these

Q24. Component of GIS.

  1. A. Data
  2. B. Hard waves
  3. C. Air flow
  4. D. a and b
Answer: D. a and b

Q25. The face left position of theodolite is also called.

  1. A. Telescope reversed
  2. B. Telescope inverted
  3. C. Telescope normal
  4. D. None of these
Answer: C. Telescope normal
