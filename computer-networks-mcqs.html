Q1. The IP address version that uses 128 bits is:

  1. A. IPv6
  2. B. IPv4
  3. C. IPv3
  4. D. IPv5
Answer: A. IPv6

Q2. Which device connects different networks and forwards packets?

  1. A. Router
  2. B. Hub
  3. C. Repeater
  4. D. Modem only
Answer: A. Router

Q3. HTTP normally uses the default port number:

  1. A. 25
  2. B. 443
  3. C. 80
  4. D. 21
Answer: C. 80

Q4. HTTPS normally uses the default port number:

  1. A. 80
  2. B. 22
  3. C. 443
  4. D. 110
Answer: C. 443

Q5. Which layer of the OSI model is responsible for routing?

  1. A. Session layer
  2. B. Network layer
  3. C. Data link layer
  4. D. Transport layer
Answer: B. Network layer

Q6. DNS is used to:

  1. A. Encrypt emails
  2. B. Translate domain names into IP addresses
  3. C. Block ads
  4. D. Assign MAC addresses
Answer: B. Translate domain names into IP addresses

Q7. The OSI model has how many layers?

  1. A. 4
  2. B. 6
  3. C. 5
  4. D. 7
Answer: D. 7

Q8. Which protocol is used to send email?

  1. A. SNMP
  2. B. DHCP
  3. C. SMTP
  4. D. FTP
Answer: C. SMTP

Q9. DHCP is used to:

  1. A. Translate names
  2. B. Transfer files
  3. C. Encrypt data
  4. D. Assign IP addresses automatically
Answer: D. Assign IP addresses automatically

Q10. A MAC address is:

  1. A. A hardware address of a network card
  2. B. A website name
  3. C. A software licence
  4. D. A port number
Answer: A. A hardware address of a network card

Q11. Which network topology connects all devices to a central hub or switch?

  1. A. Bus Topology
  2. B. Ring Topology
  3. C. Star Topology
  4. D. Mesh Topology
Answer: C. Star Topology

Q12. Which layer of the OSI model is responsible for reliable end-to-end communication and flow control?

  1. A. Physical Layer
  2. B. Network Layer
  3. C. Transport Layer
  4. D. Data Link Layer
Answer: C. Transport Layer

Q13. Which OSI layer is responsible for end-to-end reliable data delivery and flow control?

  1. A. Physical Layer
  2. B. Data Link Layer
  3. C. Transport Layer
  4. D. Network Layer
Answer: C. Transport Layer

Q14. Which IP address version uses 128-bit addresses?

  1. A. IPv4
  2. B. IPv6
  3. C. IPv5
  4. D. IPv7
Answer: B. IPv6

Q15. What is the primary function of a subnet mask in IPv4 addressing?

  1. A. To divide an IP address into network and host portions
  2. B. To convert domain names to IP addresses
  3. C. To encrypt network traffic
  4. D. To assign dynamic IP addresses to devices
Answer: A. To divide an IP address into network and host portions

Q16. What is the primary function of a Subnet Mask in computer networking?

  1. A. To convert domain names to IP addresses
  2. B. To divide an IP address into network and host portions
  3. C. To encrypt data packets during transmission
  4. D. To assign dynamic IP addresses to devices
Answer: B. To divide an IP address into network and host portions

Q17. What is the main function of a router in a computer network?

  1. A. Amplifying signals
  2. B. Forwarding data packets between networks
  3. C. Broadcasting data to all nodes
  4. D. Converting digital signals to analog
Answer: B. Forwarding data packets between networks

Q18. Which protocol is primarily used for secure communication over a computer network, particularly on the World Wide Web?

  1. A. HTTP
  2. B. FTP
  3. C. HTTPS
  4. D. SMTP
Answer: C. HTTPS

Q19. Which protocol is securely used for fetching emails from a remote mail server over port 993?

  1. A. POP3
  2. B. IMAPS
  3. C. SMTP
  4. D. HTTP
Answer: B. IMAPS

Q20. What is the default port number for HTTP protocol?

  1. A. 21
  2. B. 80
  3. C. 443
  4. D. 8080
Answer: B. 80
