Q1. Which is an example of a preventive control?

  1. A. Exception report review
  2. B. Bank reconciliation review
  3. C. After-the-event audit
  4. D. Password access control
Answer: D. Password access control

Q2. A database management system is used to:

  1. A. Browse the internet
  2. B. Print documents only
  3. C. Create and manage databases
  4. D. Send emails only
Answer: C. Create and manage databases

Q3. Risk appetite is the:

  1. A. Insurance premium
  2. B. Total of all losses
  3. C. Number of risks listed
  4. D. Amount of risk an entity is willing to accept
Answer: D. Amount of risk an entity is willing to accept

Q4. Phishing is an attempt to:

  1. A. Back up data
  2. B. Speed up a network
  3. C. Trick users into revealing sensitive information
  4. D. Update software
Answer: C. Trick users into revealing sensitive information

Q5. Regular offsite data backups help to reduce the impact of:

  1. A. Slow typing
  2. B. Tax audits
  3. C. Data loss
  4. D. Low demand
Answer: C. Data loss

Q6. A firewall is used to:

  1. A. Control network traffic
  2. B. Store accounting data
  3. C. Print reports
  4. D. Calculate depreciation
Answer: A. Control network traffic

Q7. Which of these is a database key that uniquely identifies a record?

  1. A. Foreign comment
  2. B. Primary key
  3. C. Cell note
  4. D. Index page
Answer: B. Primary key

Q8. Risk management involves identifying, assessing and:

  1. A. Hiding risks
  2. B. Responding to risks
  3. C. Ignoring risks
  4. D. Transferring all risks to auditors
Answer: B. Responding to risks

Q9. Segregation of duties mainly reduces the risk of:

  1. A. Low sales
  2. B. Slow processing
  3. C. Fraud and error
  4. D. High taxes
Answer: C. Fraud and error

Q10. Two-factor authentication requires:

  1. A. Two users to log in
  2. B. Two passwords of the same type
  3. C. Two different forms of proof of identity
  4. D. A paid licence
Answer: C. Two different forms of proof of identity

Q11. What is the primary purpose of conducting a vulnerability assessment in an IT system?

  1. A. To eliminate all potential hardware failures completely
  2. B. To identify and quantify security weaknesses before exploitation
  3. C. To increase the overall data storage capacity
  4. D. To speed up network routing protocols
Answer: B. To identify and quantify security weaknesses before exploitation

Q12. Which term describes the maximum acceptable period of data loss following a disruptive incident?

  1. A. Recovery Time Objective
  2. B. Recovery Point Objective
  3. C. Maximum Tolerable Downtime
  4. D. Business Impact Analysis
Answer: B. Recovery Point Objective

Q13. In system development, what is the main benefit of implementing input validation controls?

  1. A. Ensuring data is entered faster by operators
  2. B. Preventing malformed or malicious data from entering the database
  3. C. Reducing the total cost of server maintenance
  4. D. Eliminating the need for user authentication
Answer: B. Preventing malformed or malicious data from entering the database

Q14. Which of the following best defines a detective technical control?

  1. A. Encryption of sensitive databases
  2. B. Intrusion detection systems monitoring network traffic
  3. C. Firewalls blocking unauthorized IP addresses
  4. D. Biometric access control doors at server room entrances
Answer: B. Intrusion detection systems monitoring network traffic

Q15. What does the CIA triad stand for in information security frameworks?

  1. A. Control, Integrity, Authorization
  2. B. Confidentiality, Integrity, Availability
  3. C. Compatibility, Infrastructure, Audit
  4. D. Configuration, Identification, Access
Answer: B. Confidentiality, Integrity, Availability

Q16. What is the primary role of a database transaction log during a system crash recovery?

  1. A. To compress historical tables to save disk space
  2. B. To record all changes so operations can be rolled back or forward
  3. C. To automatically generate daily management reports
  4. D. To scan incoming user queries for virus signatures
Answer: B. To record all changes so operations can be rolled back or forward

Q17. Which of the following is a characteristic of big data that directly impacts data storage requirements?

  1. A. Low velocity
  2. B. High variety
  3. C. Small volume
  4. D. Uniform structure
Answer: B. High variety

Q18. What is the main advantage of using a relational database management system (RDBMS) for transaction processing?

  1. A. It stores data in plain text files
  2. B. It allows concurrent access with ACID compliance
  3. C. It requires no indexing for queries
  4. D. It eliminates the need for backup
Answer: B. It allows concurrent access with ACID compliance

Q19. In risk management, the term 'risk appetite' refers to:

  1. A. The maximum loss an organization is willing to accept
  2. B. The amount of risk that must be eliminated
  3. C. The probability of a risk occurring
  4. D. The cost of implementing controls
Answer: A. The maximum loss an organization is willing to accept

Q20. Which of the following best describes the primary purpose of a data backup strategy in a cloud‑based ERP system?

  1. A. To eliminate the need for disaster recovery
  2. B. To provide a copy of data for future reference only
  3. C. To ensure business continuity in case of data loss
  4. D. To increase storage costs without benefits
Answer: C. To ensure business continuity in case of data loss

Q21. Which control type is most effective for detecting unauthorized access to a financial reporting system?

  1. A. Preventive
  2. B. Deterrent
  3. C. Detective
  4. D. Corrective
Answer: C. Detective

Q22. What is the primary purpose of a vulnerability assessment in an IT system?

  1. A. To patch all software automatically
  2. B. To identify weaknesses before exploitation
  3. C. To replace outdated hardware
  4. D. To train staff on security policies
Answer: B. To identify weaknesses before exploitation

Q23. Which information security objective ensures that sensitive financial records are only accessed by authorized personnel?

  1. A. Availability
  2. B. Confidentiality
  3. C. Redundancy
  4. D. Scalability
Answer: B. Confidentiality

Q24. In a relational database management system, what is the purpose of database normalization?

  1. A. To duplicate data across multiple independent tables
  2. B. To encrypt passwords using hashing algorithms
  3. C. To organize data to reduce redundancy and improve data integrity
  4. D. To increase the overall file size of backup archives
Answer: C. To organize data to reduce redundancy and improve data integrity

Q25. Which of the following best exemplifies a preventative physical security control in a corporate data center?

  1. A. A motion-activated floodlight outside the building
  2. B. Biometric fingerprint scanners on server room doors
  3. C. A log file recording failed login attempts
  4. D. An automated smoke detector alarm
Answer: B. Biometric fingerprint scanners on server room doors
