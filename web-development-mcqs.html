Q1. HTML stands for:

  1. A. Hyper Tool Markup Language
  2. B. HyperText Markup Language
  3. C. Home Text Markup Language
  4. D. HighText Machine Language
Answer: B. HyperText Markup Language

Q2. Which tag creates a hyperlink in HTML?

  1. A. <link-text>
  2. B. <url>
  3. C. <a>
  4. D. <href>
Answer: C. <a>

Q3. CSS is used mainly for:

  1. A. Server logic
  2. B. Styling web pages
  3. C. Database queries
  4. D. Storing data
Answer: B. Styling web pages

Q4. Which language runs in the browser to add interactivity?

  1. A. Python only
  2. B. JavaScript
  3. C. SQL
  4. D. Java servlet
Answer: B. JavaScript

Q5. Which HTML tag defines the largest heading?

  1. A. <title>
  2. B. <h1>
  3. C. <head>
  4. D. <h6>
Answer: B. <h1>

Q6. Which CSS property changes the text colour?

  1. A. background
  2. B. text-align
  3. C. font-style
  4. D. color
Answer: D. color

Q7. In HTTP, which method is normally used to send form data to a server?

  1. A. GET only
  2. B. TRACE
  3. C. POST
  4. D. HEAD
Answer: C. POST

Q8. A responsive website:

  1. A. Has no CSS
  2. B. Uses only images
  3. C. Loads only on desktop
  4. D. Adapts to different screen sizes
Answer: D. Adapts to different screen sizes

Q9. JSON stands for:

  1. A. Joint Script Online Notation
  2. B. Java Standard Object Network
  3. C. JavaScript Object Notation
  4. D. JavaScript Orbit Node
Answer: C. JavaScript Object Notation

Q10. Which attribute in <img> gives alternative text?

  1. A. title only
  2. B. alt
  3. C. href
  4. D. src
Answer: B. alt

Q11. Which HTTP status code indicates that a requested web page was not found?

  1. A. 200 OK
  2. B. 301 Moved Permanently
  3. C. 404 Not Found
  4. D. 500 Internal Server Error
Answer: C. 404 Not Found

Q12. In a RESTful API, which HTTP method is typically used to retrieve data without modifying the server state?

  1. A. PUT
  2. B. DELETE
  3. C. GET
  4. D. PATCH
Answer: C. GET

Q13. Which HTTP response code tells the client that the request was successful and the server is returning the requested resource?

  1. A. 200 OK
  2. B. 301 Moved Permanently
  3. C. 404 Not Found
  4. D. 500 Internal Server Error
Answer: A. 200 OK

Q14. What is the primary purpose of the <script> tag in an HTML document?

  1. A. To link external stylesheets
  2. B. To embed JavaScript code
  3. C. To define page metadata
  4. D. To create tables
Answer: B. To embed JavaScript code

Q15. Which HTML element is used to embed an image in a web page?

  1. A. <img>
  2. B. <image>
  3. C. <src>
  4. D. <picture>
Answer: A. <img>

Q16. Which HTTP status code indicates that the server encountered an unexpected condition that prevented it from fulfilling the request?

  1. A. 400 Bad Request
  2. B. 401 Unauthorized
  3. C. 403 Forbidden
  4. D. 500 Internal Server Error
Answer: D. 500 Internal Server Error

Q17. Which CSS selector targets all elements with the class name "highlight"?

  1. A. .highlight
  2. B. #highlight
  3. C. highlight
  4. D. *highlight
Answer: A. .highlight
