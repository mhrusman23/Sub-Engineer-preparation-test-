Q1. Which shortcut is used to copy in MS Office?

  1. A. Ctrl+V
  2. B. Ctrl+Z
  3. C. Ctrl+X
  4. D. Ctrl+C
Answer: D. Ctrl+C

Q2. Which shortcut is used to paste?

  1. A. Ctrl+P
  2. B. Ctrl+C
  3. C. Ctrl+S
  4. D. Ctrl+V
Answer: D. Ctrl+V

Q3. In Excel, a formula always begins with:

  1. A. #
  2. B. =
  3. C. $
  4. D. @
Answer: B. =

Q4. Which Excel function adds a range of numbers?

  1. A. SUM
  2. B. TOTAL only
  3. C. ADD
  4. D. PLUS
Answer: A. SUM

Q5. The default file extension of a Word 2016 document is:

  1. A. .xlsx
  2. B. .docx
  3. C. .pptx
  4. D. .txt
Answer: B. .docx

Q6. PowerPoint is mainly used to create:

  1. A. Spreadsheets
  2. B. Emails
  3. C. Presentations
  4. D. Databases
Answer: C. Presentations

Q7. Which shortcut saves a document?

  1. A. Ctrl+B
  2. B. Ctrl+S
  3. C. Ctrl+O
  4. D. Ctrl+N
Answer: B. Ctrl+S

Q8. 1 KB equals:

  1. A. 100 bytes
  2. B. 1024 bytes
  3. C. 1000 bits
  4. D. 8 bytes
Answer: B. 1024 bytes

Q9. Which key combination undoes the last action?

  1. A. Ctrl+Z
  2. B. Ctrl+K
  3. C. Ctrl+A
  4. D. Ctrl+Y
Answer: A. Ctrl+Z

Q10. An Excel cell reference like B3 shows:

  1. A. Row B and column 3
  2. B. Chart B3
  3. C. Sheet B of page 3
  4. D. Column B and row 3
Answer: D. Column B and row 3

Q11. Which combination on the keyboard allows a user to quickly rename a selected file or folder in Windows?

  1. A. F2
  2. B. F5
  3. C. F7
  4. D. F12
Answer: A. F2

Q12. Which view in Microsoft PowerPoint is best suited for reordering slides and getting a complete visual overview of the entire presentation?

  1. A. Slide Show View
  2. B. Slide Sorter View
  3. C. Reading View
  4. D. Normal View
Answer: B. Slide Sorter View

Q13. Which keyboard shortcut is used to open the Find and Replace dialog box directly in Microsoft Word?

  1. A. Ctrl + F
  2. B. Ctrl + H
  3. C. Ctrl + G
  4. D. Ctrl + R
Answer: B. Ctrl + H

Q14. What is the primary function of the absolute cell reference symbol ($) when used in Microsoft Excel formulas?

  1. A. To multiply the cell value by currency rates
  2. B. To lock the specific row or column reference when copying formulas
  3. C. To check for errors in the formula calculation
  4. D. To format the output text as a financial amount
Answer: B. To lock the specific row or column reference when copying formulas

Q15. Which specific alignment option spreads text evenly between both the left and right margins in a word processor?

  1. A. Center
  2. B. Left
  3. C. Justify
  4. D. Right
Answer: C. Justify

Q16. Which function key is universally used in Microsoft Excel to open the Insert Function dialog box?

  1. A. Shift + F3
  2. B. Alt + F1
  3. C. Ctrl + F4
  4. D. F9
Answer: A. Shift + F3
