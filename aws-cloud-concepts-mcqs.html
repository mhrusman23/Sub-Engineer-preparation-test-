Q1. Cloud computing is best described as:

  1. A. Owning servers
  2. B. On-demand delivery of IT resources over the internet with pay-as-you-go pricing
  3. C. Free software
  4. D. A type of cable
Answer: B. On-demand delivery of IT resources over the internet with pay-as-you-go pricing

Q2. Which is an Infrastructure as a Service (IaaS) example?

  1. A. Gmail
  2. B. Amazon EC2
  3. C. Salesforce
  4. D. Netflix
Answer: B. Amazon EC2

Q3. The AWS global infrastructure is built from:

  1. A. Data centres only
  2. B. Regions and Availability Zones
  3. C. Countries and cities
  4. D. Offices
Answer: B. Regions and Availability Zones

Q4. Elasticity in the cloud means:

  1. A. Fixed capacity
  2. B. Automatically scaling resources up and down with demand
  3. C. Cheaper hardware
  4. D. Manual scaling
Answer: B. Automatically scaling resources up and down with demand

Q5. Which AWS service is object storage?

  1. A. Amazon EC2
  2. B. Amazon S3
  3. C. Amazon RDS
  4. D. Amazon VPC
Answer: B. Amazon S3

Q6. The shared responsibility model means:

  1. A. AWS does everything
  2. B. AWS secures the cloud itself; the customer secures what they put in the cloud
  3. C. The customer does everything
  4. D. Security is shared with other customers
Answer: B. AWS secures the cloud itself; the customer secures what they put in the cloud

Q7. Which is a benefit of cloud over on-premises?

  1. A. Buying hardware upfront
  2. B. Trade capital expense for variable expense
  3. C. More maintenance
  4. D. Fixed capacity
Answer: B. Trade capital expense for variable expense

Q8. Amazon RDS is a service for:

  1. A. Files
  2. B. Managed relational databases
  3. C. Videos
  4. D. Emails
Answer: B. Managed relational databases

Q9. High availability means a system:

  1. A. Is cheap
  2. B. Stays operational with minimal downtime, even if a component fails
  3. C. Is fast
  4. D. Has many users
Answer: B. Stays operational with minimal downtime, even if a component fails

Q10. Which AWS service delivers content with low latency using edge locations?

  1. A. Amazon S3
  2. B. Amazon CloudFront
  3. C. Amazon EC2
  4. D. AWS Lambda
Answer: B. Amazon CloudFront

Q11. Which cloud architectural design principle focuses on building systems that can automatically recover from hardware or service failures?

  1. A. Tight coupling
  2. B. Static resource allocation
  3. C. Manual failover
  4. D. Fault tolerance and high availability
Answer: D. Fault tolerance and high availability

Q12. Which AWS service is commonly deployed to decouple application components by acting as a reliable managed message queue?

  1. A. Amazon Redshift
  2. B. Amazon Simple Queue Service (SQS)
  3. C. Amazon Elastic File System (EFS)
  4. D. AWS Direct Connect
Answer: B. Amazon Simple Queue Service (SQS)

Q13. Which AWS service allows organizations to create and manage authorized portfolios of products for centralized deployment?

  1. A. AWS Service Catalog
  2. B. AWS CloudTrail
  3. C. AWS Systems Manager
  4. D. AWS Trusted Advisor
Answer: A. AWS Service Catalog

Q14. In cloud architecture, what does the concept of 'decoupling' refer to?

  1. A. Breaking applications into smaller, independent components that operate autonomously
  2. B. Combining all presentation and database layers into a single monolithic server
  3. C. Disconnecting cloud services from the AWS global network
  4. D. Removing encryption protocols between microservices to improve speed
Answer: A. Breaking applications into smaller, independent components that operate autonomously

Q15. Which of the following activities falls within the direct scope of standard AWS Support?

  1. A. Writing custom application source code
  2. B. Troubleshooting AWS API integration issues
  3. C. Performing database query tuning for custom apps
  4. D. Debugging third-party operating systems
Answer: B. Troubleshooting AWS API integration issues

Q16. What is a primary advantage of utilizing serverless computing architectures for workloads with variable traffic?

  1. A. It eliminates the need for any database design
  2. B. It allows developers to bypass security patches entirely
  3. C. It automatically scales compute resources up or down without manual intervention and eliminates idle costs
  4. D. It locks the organization into a single fixed monthly hosting fee
Answer: C. It automatically scales compute resources up or down without manual intervention and eliminates idle costs

Q17. Which AWS compute service automatically runs code in response to events without requiring server management?

  1. A. Amazon EC2
  2. B. AWS Lambda
  3. C. Amazon ECS
  4. D. AWS Elastic Beanstalk
Answer: B. AWS Lambda

Q18. What is the primary function of an Amazon VPC in the AWS Cloud?

  1. A. To store relational database records securely
  2. B. To isolate resources within a logically defined virtual network
  3. C. To distribute incoming internet traffic across multiple backend instances
  4. D. To accelerate static and dynamic web content delivery globally
Answer: B. To isolate resources within a logically defined virtual network

Q19. Which AWS pricing model enables customers to pay for compute capacity hourly or secondarily without long-term commitments?

  1. A. Spot Instances
  2. B. Reserved Instances
  3. C. On-Demand Instances
  4. D. Dedicated Hosts
Answer: C. On-Demand Instances

Q20. Which component of the AWS global infrastructure consists of one or more discrete data centers with redundant power and networking?

  1. A. Edge Location
  2. B. Availability Zone
  3. C. AWS Region
  4. D. Transit Gateway
Answer: B. Availability Zone

Q21. Which AWS security tool evaluates configurations for potential vulnerabilities and recommends deviations from security best practices?

  1. A. Amazon CloudWatch
  2. B. AWS IAM
  3. C. AWS Trusted Advisor
  4. D. AWS CloudTrail
Answer: C. AWS Trusted Advisor

Q22. What is the primary benefit of deploying applications across multiple AWS Regions?

  1. A. Eliminating the need for database backups
  2. B. Ensuring business continuity and disaster recovery resilience
  3. C. Reducing data transfer costs to zero
  4. D. Bypassing regional compliance regulations
Answer: B. Ensuring business continuity and disaster recovery resilience

Q23. Which AWS service assists with cost optimization by analyzing historical usage and recommending optimal EC2 instance sizing?

  1. A. AWS Cost Explorer
  2. B. AWS Budgets
  3. C. AWS Trusted Advisor
  4. D. Amazon CloudWatch
Answer: C. AWS Trusted Advisor

Q24. Which AWS support plan provides access to a dedicated Technical Account Manager (TAM)?

  1. A. Basic
  2. B. Developer
  3. C. Business
  4. D. Enterprise
Answer: D. Enterprise

Q25. What is the main purpose of an Elastic Load Balancer (ELB) in AWS?

  1. A. To store backup files securely
  2. B. To automatically distribute incoming application traffic across multiple targets
  3. C. To manage relational database queries efficiently
  4. D. To monitor resource utilization and send alerts
Answer: B. To automatically distribute incoming application traffic across multiple targets
