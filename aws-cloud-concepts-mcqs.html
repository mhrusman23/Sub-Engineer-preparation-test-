Q1. Cloud computing is best described as:

  1. A. Owning servers
  2. B. On-demand delivery of IT resources over the internet with pay-as-you-go pricing
  3. C. Free software
  4. D. A type of cable
Answer: B. On-demand delivery of IT resources over the internet with pay-as-you-go pricing

Q2. Which is an Infrastructure as a Service (IaaS) example?

  1. A. Gmail
  2. B. Amazon EC2
  3. C. Salesforce
  4. D. Netflix
Answer: B. Amazon EC2

Q3. The AWS global infrastructure is built from:

  1. A. Data centres only
  2. B. Regions and Availability Zones
  3. C. Countries and cities
  4. D. Offices
Answer: B. Regions and Availability Zones

Q4. Elasticity in the cloud means:

  1. A. Fixed capacity
  2. B. Automatically scaling resources up and down with demand
  3. C. Cheaper hardware
  4. D. Manual scaling
Answer: B. Automatically scaling resources up and down with demand

Q5. Which AWS service is object storage?

  1. A. Amazon EC2
  2. B. Amazon S3
  3. C. Amazon RDS
  4. D. Amazon VPC
Answer: B. Amazon S3

Q6. The shared responsibility model means:

  1. A. AWS does everything
  2. B. AWS secures the cloud itself; the customer secures what they put in the cloud
  3. C. The customer does everything
  4. D. Security is shared with other customers
Answer: B. AWS secures the cloud itself; the customer secures what they put in the cloud

Q7. Which is a benefit of cloud over on-premises?

  1. A. Buying hardware upfront
  2. B. Trade capital expense for variable expense
  3. C. More maintenance
  4. D. Fixed capacity
Answer: B. Trade capital expense for variable expense

Q8. Amazon RDS is a service for:

  1. A. Files
  2. B. Managed relational databases
  3. C. Videos
  4. D. Emails
Answer: B. Managed relational databases

Q9. High availability means a system:

  1. A. Is cheap
  2. B. Stays operational with minimal downtime, even if a component fails
  3. C. Is fast
  4. D. Has many users
Answer: B. Stays operational with minimal downtime, even if a component fails

Q10. Which AWS service delivers content with low latency using edge locations?

  1. A. Amazon S3
  2. B. Amazon CloudFront
  3. C. Amazon EC2
  4. D. AWS Lambda
Answer: B. Amazon CloudFront
