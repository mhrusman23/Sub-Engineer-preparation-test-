PTE Reading MCQs (IELTS & English Tests)

Free MCQs with answers for PTE Reading. 20 questions in 2 chapter tests are in the app; all are shown here.

Q1. PTE 'Multiple Choice, Multiple Answers' questions have:

  1. A. Negative marking for wrong choices
  2. B. No penalty ever
  3. C. Only one answer
  4. D. Spoken answers
Answer: A. Negative marking for wrong choices

Q2. In 'Re-order Paragraphs', you must:

  1. A. Write new paragraphs
  2. B. Put jumbled paragraphs in the correct order
  3. C. Translate paragraphs
  4. D. Count the words
Answer: B. Put jumbled paragraphs in the correct order

Q3. 'Reading & Writing: Fill in the Blanks' tests:

  1. A. Listening
  2. B. Vocabulary and grammar in context
  3. C. Pronunciation
  4. D. Handwriting
Answer: B. Vocabulary and grammar in context

Q4. A collocation is:

  1. A. A type of question
  2. B. Words that naturally go together
  3. C. A punctuation mark
  4. D. A reading speed
Answer: B. Words that naturally go together

Q5. For PTE Reading time management, it is wise to:

  1. A. Spend equal time on every item
  2. B. Not spend too long on any single item
  3. C. Skip the fill-in blanks
  4. D. Read everything twice
Answer: B. Not spend too long on any single item

Q6. In single-answer multiple choice, the correct option is usually:

  1. A. The longest one
  2. B. A paraphrase of the text
  3. C. The first one
  4. D. Written in capital letters
Answer: B. A paraphrase of the text

Q7. 'Fill in the Blanks' (dropdown) answers depend mostly on:

  1. A. Luck
  2. B. Grammar and meaning in context
  3. C. The passage title
  4. D. Word length
Answer: B. Grammar and meaning in context

Q8. Skimming in PTE Reading helps you:

  1. A. Memorise details
  2. B. Get the gist quickly
  3. C. Improve pronunciation
  4. D. Write essays
Answer: B. Get the gist quickly

Q9. If unsure in multiple-answers questions, it is safer to:

  1. A. Select every option
  2. B. Select only options you are confident about
  3. C. Select none
  4. D. Select the longest options
Answer: B. Select only options you are confident about

Q10. PTE Reading section timing is:

  1. A. Untimed
  2. B. Strictly timed as one section
  3. C. Timed per question by a teacher
  4. D. Optional
Answer: B. Strictly timed as one section

Q11. In Re-order Paragraphs, look first for:

  1. A. The longest sentence
  2. B. The sentence that can stand alone as an introduction (no pronouns like 'this' pointing back)
  3. C. The last sentence
  4. D. A question
Answer: B. The sentence that can stand alone as an introduction (no pronouns like 'this' pointing back)

Q12. Pronouns like 'this', 'these' and 'it' in a sentence suggest:

  1. A. It is the first sentence
  2. B. It refers to something in an earlier sentence
  3. C. It is the conclusion
  4. D. It is unimportant
Answer: B. It refers to something in an earlier sentence

Q13. For multiple-choice single answer, eliminate options that:

  1. A. Are short
  2. B. Are too extreme ('always', 'never') when the text is softer
  3. C. Use synonyms
  4. D. Are in the middle
Answer: B. Are too extreme ('always', 'never') when the text is softer

Q14. Fill-in-the-blanks (reading) often tests collocations, so choose the word that:

  1. A. Sounds longest
  2. B. Naturally fits with the words around it
  3. C. Is rarest
  4. D. Is capitalised
Answer: B. Naturally fits with the words around it

Q15. Time per reading item should be:

  1. A. Unlimited
  2. B. About 2 minutes — keep moving
  3. C. 10 minutes
  4. D. 10 seconds
Answer: B. About 2 minutes — keep moving

Q16. A paragraph mainly about 'causes' will use words like:

  1. A. 'However'
  2. B. 'Due to', 'leads to', 'results in'
  3. C. 'For example' only
  4. D. 'Finally' only
Answer: B. 'Due to', 'leads to', 'results in'

Q17. In multiple-answers questions, selecting an extra wrong option:

  1. A. Costs nothing
  2. B. Loses a mark (but not below zero for the item)
  3. C. Doubles marks
  4. D. Cancels the test
Answer: B. Loses a mark (but not below zero for the item)

Q18. Skim the passage first to know:

  1. A. Every detail
  2. B. The topic of each paragraph
  3. C. The answers
  4. D. The author
Answer: B. The topic of each paragraph

Q19. Words in the options that copy the text exactly may be:

  1. A. Always right
  2. B. Distractors — check the meaning carefully
  3. C. Always wrong
  4. D. The key
Answer: B. Distractors — check the meaning carefully

Q20. If a blank needs a verb after 'to', choose:

  1. A. A past tense
  2. B. The base form of the verb
  3. C. An adjective
  4. D. A plural noun
Answer: B. The base form of the verb
