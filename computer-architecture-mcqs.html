Q1. The brain of the computer is the:

  1. A. CPU
  2. B. Hard disk
  3. C. Mouse
  4. D. Monitor
Answer: A. CPU

Q2. The ALU performs:

  1. A. Arithmetic and logic operations
  2. B. Display output
  3. C. Printing
  4. D. Networking
Answer: A. Arithmetic and logic operations

Q3. Which memory is volatile?

  1. A. RAM
  2. B. ROM
  3. C. SSD
  4. D. Hard disk
Answer: A. RAM

Q4. Cache memory is placed between the CPU and:

  1. A. Printer
  2. B. Keyboard
  3. C. Monitor
  4. D. Main memory
Answer: D. Main memory

Q5. 1 byte equals:

  1. A. 4 bits
  2. B. 16 bits
  3. C. 2 bits
  4. D. 8 bits
Answer: D. 8 bits

Q6. The register that holds the address of the next instruction is the:

  1. A. Stack pointer
  2. B. Status register
  3. C. Accumulator
  4. D. Program counter
Answer: D. Program counter

Q7. Which bus carries memory addresses?

  1. A. Power bus
  2. B. Control bus
  3. C. Address bus
  4. D. Data bus
Answer: C. Address bus

Q8. A 32-bit CPU can directly address up to how many bytes of memory?

  1. A. 4 GB
  2. B. 16 GB
  3. C. 8 GB
  4. D. 2 GB
Answer: A. 4 GB

Q9. RISC stands for reduced instruction set:

  1. A. Control
  2. B. Code
  3. C. Cache
  4. D. Computer
Answer: D. Computer

Q10. Pipelining improves CPU:

  1. A. Instruction throughput
  2. B. Screen size
  3. C. Battery colour
  4. D. Disk size
Answer: A. Instruction throughput

Q11. Which memory type retains its contents even when the computer power is turned off?

  1. A. RAM
  2. B. Cache Memory
  3. C. ROM
  4. D. Registers
Answer: C. ROM

Q12. Which of the following is considered volatile memory?

  1. A. ROM
  2. B. RAM
  3. C. Hard Disk
  4. D. Flash Drive
Answer: B. RAM

Q13. Which bus is primarily used to transfer data between the CPU and main memory?

  1. A. Control bus
  2. B. Address bus
  3. C. Data bus
  4. D. Power bus
Answer: C. Data bus

Q14. The unit that performs logical and arithmetic operations in a processor is called:

  1. A. Control unit
  2. B. ALU
  3. C. Cache
  4. D. Register file
Answer: B. ALU

Q15. Which type of memory retains data only while power is supplied?

  1. A. ROM
  2. B. Flash
  3. C. RAM
  4. D. EEPROM
Answer: C. RAM

Q16. Which register holds the address of the instruction currently being executed?

  1. A. Instruction register
  2. B. Program counter
  3. C. Stack pointer
  4. D. Status register
Answer: B. Program counter

Q17. Pipelining in a CPU primarily improves:

  1. A. Clock speed
  2. B. Instruction throughput
  3. C. Power consumption
  4. D. Cache size
Answer: B. Instruction throughput
