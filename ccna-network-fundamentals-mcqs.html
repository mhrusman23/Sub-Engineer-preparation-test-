Q1. What does IP stand for?

  1. A. Internet Protocol
  2. B. Internal Program
  3. C. Internet Page
  4. D. Interconnected Port
Answer: A. Internet Protocol

Q2. A switch operates mainly at which OSI layer?

  1. A. Layer 1
  2. B. Layer 2
  3. C. Layer 3
  4. D. Layer 7
Answer: B. Layer 2

Q3. The OSI model has how many layers?

  1. A. 4
  2. B. 5
  3. C. 7
  4. D. 9
Answer: C. 7

Q4. A router's main job is to:

  1. A. Store files
  2. B. Forward packets between different networks
  3. C. Print documents
  4. D. Charge devices
Answer: B. Forward packets between different networks

Q5. Which address is a private IPv4 address?

  1. A. 8.8.8.8
  2. B. 192.168.1.10
  3. C. 1.1.1.1
  4. D. 203.0.113.5
Answer: B. 192.168.1.10

Q6. TCP differs from UDP because TCP is:

  1. A. Connectionless
  2. B. Reliable and connection-oriented
  3. C. Faster always
  4. D. Used only for video
Answer: B. Reliable and connection-oriented

Q7. DNS is used to:

  1. A. Encrypt data
  2. B. Translate domain names into IP addresses
  3. C. Assign IP addresses
  4. D. Block websites
Answer: B. Translate domain names into IP addresses

Q8. A MAC address is:

  1. A. A logical address
  2. B. A unique physical (hardware) address of a network interface
  3. C. An email address
  4. D. A password
Answer: B. A unique physical (hardware) address of a network interface

Q9. The default subnet mask of a Class C network is:

  1. A. 255.0.0.0
  2. B. 255.255.0.0
  3. C. 255.255.255.0
  4. D. 255.255.255.255
Answer: C. 255.255.255.0

Q10. Which cable type is used inside LANs most commonly?

  1. A. Coaxial only
  2. B. Twisted pair (Ethernet)
  3. C. Power cable
  4. D. HDMI
Answer: B. Twisted pair (Ethernet)
