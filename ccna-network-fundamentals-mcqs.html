Q1. What does IP stand for?

  1. A. Internet Protocol
  2. B. Internal Program
  3. C. Internet Page
  4. D. Interconnected Port
Answer: A. Internet Protocol

Q2. A switch operates mainly at which OSI layer?

  1. A. Layer 1
  2. B. Layer 2
  3. C. Layer 3
  4. D. Layer 7
Answer: B. Layer 2

Q3. A router's main job is to:

  1. A. Store files
  2. B. Forward packets between different networks
  3. C. Print documents
  4. D. Charge devices
Answer: B. Forward packets between different networks

Q4. Which address is a private IPv4 address?

  1. A. 8.8.8.8
  2. B. 192.168.1.10
  3. C. 1.1.1.1
  4. D. 203.0.113.5
Answer: B. 192.168.1.10

Q5. TCP differs from UDP because TCP is:

  1. A. Connectionless
  2. B. Reliable and connection-oriented
  3. C. Faster always
  4. D. Used only for video
Answer: B. Reliable and connection-oriented

Q6. The default subnet mask of a Class C network is:

  1. A. 255.0.0.0
  2. B. 255.255.0.0
  3. C. 255.255.255.0
  4. D. 255.255.255.255
Answer: C. 255.255.255.0

Q7. Which cable type is used inside LANs most commonly?

  1. A. Coaxial only
  2. B. Twisted pair (Ethernet)
  3. C. Power cable
  4. D. HDMI
Answer: B. Twisted pair (Ethernet)

Q8. Which protocol is utilized to dynamically translate private IP addresses to public IP addresses at the network edge?

  1. A. DHCP
  2. B. NAT
  3. C. SNMP
  4. D. NTP
Answer: B. NAT

Q9. Which layer of the OSI model is responsible for end-to-end reliable delivery and flow control?

  1. A. Layer 2
  2. B. Layer 3
  3. C. Layer 4
  4. D. Layer 7
Answer: C. Layer 4

Q10. What is the standard data format commonly used by REST APIs for transmitting structured information in network automation?

  1. A. JSON
  2. B. ASCII
  3. C. PNG
  4. D. EXE
Answer: A. JSON

Q11. Which interior gateway routing protocol uses bandwidth and delay metrics to calculate the composite metric via DUAL algorithm?

  1. A. OSPF
  2. B. RIPv2
  3. C. BGP
  4. D. EIGRP
Answer: D. EIGRP

Q12. What is the primary function of the Spanning Tree Protocol (STP) in a switched enterprise network?

  1. A. To encrypt data traversing VLAN trunks
  2. B. To prevent Layer 2 switching loops
  3. C. To automatically assign IP addresses to hosts
  4. D. To balance traffic across multiple physical links
Answer: B. To prevent Layer 2 switching loops

Q13. Which network device feature restricts access to switch ports by registering specific MAC addresses to enhance security?

  1. A. Access Control Lists
  2. B. Port Security
  3. C. Network Time Protocol
  4. D. Dynamic Host Configuration
Answer: B. Port Security

Q14. In the OSI model, which layer is responsible for reliable, connection-oriented data transport and flow control?

  1. A. A) Physical Layer
  2. B. B) Data Link Layer
  3. C. C) Transport Layer
  4. D. D) Network Layer
Answer: C. C) Transport Layer

Q15. Which protocol dynamically assigns IP addresses to clients on a local area network?

  1. A. A) DNS
  2. B. B) DHCP
  3. C. C) SNMP
  4. D. D) NTP
Answer: B. B) DHCP

Q16. Which network service synchronizes the clocks of computers and networking devices over a packet-switched network?

  1. A. A) FTP
  2. B. B) NTP
  3. C. C) SMTP
  4. D. D) Telnet
Answer: B. B) NTP

Q17. Which IEEE standard defines wireless LAN (Wi-Fi) technology principles?

  1. A. A) IEEE 802.3
  2. B. B) IEEE 802.1Q
  3. C. C) IEEE 802.11
  4. D. D) IEEE 802.1D
Answer: C. C) IEEE 802.11

Q18. What is the primary function of an access control list (ACL) in a Cisco router?

  1. A. A) Compressing network traffic
  2. B. B) Filtering network traffic based on defined rules
  3. C. C) Translating private IP addresses to public IP addresses
  4. D. D) Dynamically discovering neighboring routers
Answer: B. B) Filtering network traffic based on defined rules

Q19. What data serialization format is most commonly used when interacting with modern REST APIs in network automation?

  1. A. A) JSON
  2. B. B) CSV
  3. C. C) RTF
  4. D. D) BMP
Answer: A. A) JSON

Q20. Which IEEE standard governs wireless local area network (WLAN) technologies commonly known as Wi-Fi?

  1. A. IEEE 802.3
  2. B. IEEE 802.1Q
  3. C. IEEE 802.11
  4. D. IEEE 802.1D
Answer: C. IEEE 802.11

Q21. Which layer of the OSI model is responsible for routing packets across interconnected networks?

  1. A. Layer 1
  2. B. Layer 2
  3. C. Layer 3
  4. D. Layer 4
Answer: C. Layer 3

Q22. Which command-line tool is commonly used to test network connectivity and measure round-trip time to a destination host using ICMP echo requests?

  1. A. ping
  2. B. ipconfig
  3. C. traceroute
  4. D. netstat
Answer: A. ping

Q23. What is the total length of an IPv4 address in bits?

  1. A. 16 bits
  2. B. 32 bits
  3. C. 64 bits
  4. D. 128 bits
Answer: B. 32 bits

Q24. Which protocol is securely used by web browsers to load pages over encrypted connections using port 443?

  1. A. HTTP
  2. B. HTTPS
  3. C. FTP
  4. D. Telnet
Answer: B. HTTPS

Q25. What is the primary purpose of the DHCP protocol in a TCP/IP network?

  1. A. Resolving domain names to IP addresses
  2. B. Dynamically assigning IP addresses to hosts
  3. C. Translating private IP addresses to public ones
  4. D. Synchronizing network device clock times
Answer: B. Dynamically assigning IP addresses to hosts
