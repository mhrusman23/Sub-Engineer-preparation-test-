Q1. Surrounding or conditions in which a person or animal or plant lives or operates is called.

  1. A. Climate
  2. B. Environment
  3. C. Pollution
  4. D. Weather
Answer: B. Environment

Q2. Primary air pollution is:

  1. A. Smoke
  2. B. Ozone
  3. C. Oxygen
  4. D. All of these
Answer: A. Smoke

Q3. Source of solid waste is

  1. A. Garbage
  2. B. Sludge
  3. C. Ashes
  4. D. All of these
Answer: D. All of these

Q4. Main sources of noise are

  1. A. Industries
  2. B. Transport
  3. C. House hold
  4. D. All of these
Answer: D. All of these

Q5. Source of land pollution is

  1. A. Acid rain
  2. B. Leakage from landfill
  3. C. Rupture of underground storage tank
  4. D. All of these
Answer: D. All of these

Q6. Pulp is prepared in this industry.

  2. B. Fertilizer
  3. C. Dairy

Q7. An accident in which persons are injured is

  1. A. Plant accident
  2. B. Fire accident
  3. C. Carriage accident
  4. D. Human accident
Answer: D. Human accident

Q8. Sources of fire are

  1. A. Heat
  2. B. Oxygen
  3. C. Fuel
  4. D. All of these

Q9. An association controlling accidents in any project is

Q10. Method of fire control in which a thick blanket of CO2 foam covers the burning material is
