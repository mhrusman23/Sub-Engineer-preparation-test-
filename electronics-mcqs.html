Q1. A diode allows current to flow mainly in:

  1. A. One direction
  2. B. No direction
  3. C. Alternating directions only
  4. D. Both directions equally
Answer: A. One direction

Q2. Which semiconductor material is most widely used?

  1. A. Iron
  2. B. Gold
  3. C. Silicon
  4. D. Copper
Answer: C. Silicon

Q3. A transistor can act as a switch or an:

  1. A. Transformer
  2. B. Inductor
  3. C. Capacitor
  4. D. Amplifier
Answer: D. Amplifier

Q4. The three terminals of a BJT are emitter, base and:

  1. A. Collector
  2. B. Drain
  3. C. Source
  4. D. Gate
Answer: A. Collector

Q5. The three terminals of a MOSFET are gate, source and:

  1. A. Collector
  2. B. Emitter
  3. C. Base
  4. D. Drain
Answer: D. Drain

Q6. A Zener diode is mainly used as a:

  1. A. Amplifier
  2. B. Oscillator
  3. C. Voltage regulator
  4. D. Inductor
Answer: C. Voltage regulator

Q7. An LED emits light when it is:

  1. A. Shorted
  2. B. Forward biased
  3. C. Open
  4. D. Reverse biased
Answer: B. Forward biased

Q8. An ideal op-amp has:

  1. A. Infinite output impedance
  2. B. Zero input impedance
  3. C. Infinite input impedance
  4. D. Zero gain
Answer: C. Infinite input impedance

Q9. A low-pass filter passes:

  1. A. Low frequencies
  2. B. High frequencies only
  3. C. No frequencies
  4. D. All frequencies
Answer: A. Low frequencies

Q10. The gain of an amplifier is the ratio of output to:

  1. A. Ground
  2. B. Supply
  3. C. Input
  4. D. Load
Answer: C. Input

Q11. Which region of a BJT is heavily doped to inject a large number of carriers into the base?

  1. A. Collector
  2. B. Base
  3. C. Emitter
  4. D. Substrate
Answer: C. Emitter

Q12. In an operational amplifier, what does the term CMRR stand for?

  1. A. Current Mode Resonance Resistance
  2. B. Common-Mode Rejection Ratio
  3. C. Capacitive Modulation Response Rate
  4. D. Critical Main Rectifier Resistance
Answer: B. Common-Mode Rejection Ratio

Q13. What primary function does a Schmitt trigger circuit perform in electronic systems?

  1. A. Amplifies audio signals
  2. B. Converts sinusoidal waves into square or rectangular waves
  3. C. Steps down AC voltage
  4. D. Filters out high frequency noise
Answer: B. Converts sinusoidal waves into square or rectangular waves

Q14. Which electronic component is primarily used as a voltage-controlled variable capacitor?

  1. A. Schottky diode
  2. B. Varactor diode
  3. C. Tunnel diode
  4. D. Photodiode
Answer: B. Varactor diode

Q15. What is the typical barrier potential of a silicon PN junction diode at room temperature?

  1. A. 0.3 V
  2. B. 0.7 V
  3. C. 1.2 V
  4. D. 1.7 V
Answer: B. 0.7 V

Q16. Which configuration of a BJT transistor provides a voltage gain of approximately unity with high input impedance?

  1. A. Common Base
  2. B. Common Emitter
  3. C. Common Collector
  4. D. Differential Pair
Answer: C. Common Collector

Q17. What is the standard SI unit used for measuring capacitance?

  1. A. Henry
  2. B. Farad
  3. C. Coulomb
  4. D. Tesla
Answer: B. Farad

Q18. In a direct current resistive circuit, electrical power is calculated as the product of voltage and:

  1. A. Resistance
  2. B. Capacitance
  3. C. Current
  4. D. Inductance
Answer: C. Current

Q19. What is the primary function of a capacitor in an electronic circuit?

  1. A. Store charge
  2. B. Produce current
  3. C. Reduce voltage
  4. D. Amplify signals
Answer: A. Store charge

Q20. Which electronic component is specifically designed to oppose any change in circuit current?

  1. A. Resistor
  2. B. Inductor
  3. C. Capacitor
  4. D. Diode
Answer: B. Inductor

Q21. What is one of the primary applications of a transistor in electronic circuits?

  1. A. To regulate voltage
  2. B. To store magnetic energy
  3. C. To filter high frequencies
  4. D. To block direct current completely
Answer: A. To regulate voltage

Q22. What is the standard unit of measurement for electrical inductance?

  1. A. Weber
  2. B. Farad
  3. C. Henry
  4. D. Siemens
Answer: C. Henry

Q23. Which feedback topology is typically used in an electronic oscillator circuit to sustain continuous oscillations without an external input signal?

  1. A. Negative feedback
  2. B. Positive feedback
  3. C. Unity feedback
  4. D. Open-loop configuration
Answer: B. Positive feedback

Q24. Which of the following semiconductor devices operates on the principle of reverse breakdown and provides a stable reference voltage?

  1. A. Photodiode
  2. B. Zener diode
  3. C. Varactor diode
  4. D. Schottky diode
Answer: B. Zener diode

Q25. In a bipolar junction transistor (BJT), which region is heavily doped to ensure efficient injection of charge carriers into the base?

  1. A. Collector
  2. B. Base
  3. C. Emitter
  4. D. Substrate
Answer: C. Emitter
