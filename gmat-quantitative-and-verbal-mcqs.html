Q1. If n is an even integer, which of the following must also be even?

  1. A. n + 1
  2. B. 2n + 2
  3. C. n/2 always
  4. D. 3n + 1
Answer: B. 2n + 2

Q2. A store sells a jacket for $90 after a 10% discount. The original price was:

  1. A. $95
  2. B. $99
  3. C. $100
  4. D. $110
Answer: C. $100

Q3. In GMAT Critical Reasoning, to weaken an argument you should:

  1. A. Add a new topic
  2. B. Undermine an assumption the argument relies on
  3. C. Agree with the conclusion
  4. D. Repeat the premises
Answer: B. Undermine an assumption the argument relies on

Q4. If a car travels 150 miles in 3 hours, how far will it travel in 5 hours at the same speed?

  1. A. 200 miles
  2. B. 225 miles
  3. C. 250 miles
  4. D. 300 miles
Answer: C. 250 miles

Q5. Which fraction is largest?

  1. A. 3/5
  2. B. 5/8
  3. C. 2/3
  4. D. 7/11
Answer: C. 2/3

Q6. In Sentence Correction, a modifier placed far from what it modifies usually creates:

  1. A. A correct sentence
  2. B. A dangling/misplaced modifier error
  3. C. A stronger sentence
  4. D. A question
Answer: B. A dangling/misplaced modifier error

Q7. If x + y = 10 and x − y = 4, then x =

  1. A. 5
  2. B. 6
  3. C. 7
  4. D. 8
Answer: C. 7

Q8. Data Sufficiency questions ask whether:

  1. A. The answer is A
  2. B. The given statements are enough to answer the question
  3. C. The question is easy
  4. D. More data can be invented
Answer: B. The given statements are enough to answer the question

Q9. The average of five numbers is 20. Their sum is:

  1. A. 25
  2. B. 50
  3. C. 100
  4. D. 120
Answer: C. 100

Q10. In a Reading Comprehension passage, the primary purpose question asks about:

  1. A. A detail
  2. B. The overall reason the passage was written
  3. C. A word meaning
  4. D. The author's age
Answer: B. The overall reason the passage was written
