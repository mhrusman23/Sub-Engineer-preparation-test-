Q1. AWS IAM is used to manage:

  1. A. Billing only
  2. B. Users, groups, roles and their permissions
  3. C. Servers
  4. D. Domains
Answer: B. Users, groups, roles and their permissions

Q2. The AWS root user should be:

  1. A. Used daily
  2. B. Protected with MFA and used only when necessary
  3. C. Shared with the team
  4. D. Deleted
Answer: B. Protected with MFA and used only when necessary

Q3. An IAM role is best used for:

  1. A. Human passwords
  2. B. Giving AWS services/applications temporary permissions
  3. C. Logging in to websites
  4. D. Storing files
Answer: B. Giving AWS services/applications temporary permissions

Q4. Amazon VPC lets you:

  1. A. Send emails
  2. B. Create an isolated virtual network in AWS
  3. C. Host videos
  4. D. Buy domains
Answer: B. Create an isolated virtual network in AWS

Q5. Security groups in a VPC act as:

  1. A. Routers
  2. B. Stateful firewalls for instances
  3. C. Storage
  4. D. Load balancers
Answer: B. Stateful firewalls for instances

Q6. AWS CloudTrail records:

  1. A. Video
  2. B. API activity and account events for auditing
  3. C. Emails
  4. D. Backups
Answer: B. API activity and account events for auditing

Q7. Encryption at rest in S3 protects data:

  1. A. While moving
  2. B. While stored on disks
  3. C. In emails
  4. D. In browsers
Answer: B. While stored on disks

Q8. The principle of least privilege in IAM means:

  1. A. Give admin to everyone
  2. B. Grant only the permissions required to perform a task
  3. C. No permissions at all
  4. D. One policy for all
Answer: B. Grant only the permissions required to perform a task

Q9. An Elastic Load Balancer:

  1. A. Stores data
  2. B. Distributes incoming traffic across multiple targets
  3. C. Encrypts disks
  4. D. Creates users
Answer: B. Distributes incoming traffic across multiple targets

Q10. AWS Lambda is:

  1. A. A database
  2. B. A serverless compute service that runs code in response to events
  3. C. A storage service
  4. D. A network cable
Answer: B. A serverless compute service that runs code in response to events

Q11. When designing a secure multi-tier architecture in AWS, database instances containing sensitive data should ideally be placed in:

  1. A. A public subnet with direct internet gateway routing
  2. B. A private subnet with no direct access from the internet
  3. C. The default public VPC without any security groups
  4. D. An unmanaged external storage server outside AWS
Answer: B. A private subnet with no direct access from the internet

Q12. To secure sensitive data at rest stored in an Amazon S3 bucket, which practice is recommended?

  1. A. Expose the bucket publicly for faster retrieval
  2. B. Disable all bucket policies and access control lists
  3. C. Apply server-side encryption and restrict public access settings
  4. D. Share the AWS account root credentials with external partners
Answer: C. Apply server-side encryption and restrict public access settings

Q13. AWS Shield and AWS WAF are commonly used together to protect web applications against:

  1. A. Hardware failures in the physical data center
  2. B. Distributed Denial of Service (DDoS) attacks and common web exploits
  3. C. Accidental deletion of database backups
  4. D. Slow network speeds caused by high latency
Answer: B. Distributed Denial of Service (DDoS) attacks and common web exploits

Q14. AWS Organizations Service Control Policies (SCPs) are primarily used to:

  1. A. Manage human user passwords and rotation schedules
  2. B. Establish maximum available permissions across accounts within an organization
  3. C. Monitor real-time API calls for security auditing
  4. D. Store encrypted configuration backups in Amazon S3
Answer: B. Establish maximum available permissions across accounts within an organization

Q15. An Amazon S3 bucket policy explicitly denies access to all users, but a new statement is added to allow read-only access for a specific IAM role. What is the outcome?

  1. A. The explicit deny in the policy overrides the allow statement, keeping access blocked
  2. B. The allow statement automatically overrides the deny statement
  3. C. The bucket becomes completely deleted
  4. D. All users across the entire organization gain full admin access
Answer: A. The explicit deny in the policy overrides the allow statement, keeping access blocked

Q16. AWS IAM policies follow the principle of least privilege, which means granting:

  1. A. Full administrative access to all users by default
  2. B. Only the minimum permissions necessary to perform a specific task
  3. C. Unrestricted internet access to all backend database instances
  4. D. Temporary root-level privileges to every developer
Answer: B. Only the minimum permissions necessary to perform a specific task

Q17. Which of the following best describes the purpose of an AWS Security Hub?

  1. A. Centralized logging of all API calls
  2. B. Aggregating security findings from multiple AWS services
  3. C. Providing a managed firewall for VPCs
  4. D. Encrypting data at rest in S3
Answer: B. Aggregating security findings from multiple AWS services

Q18. Which AWS service provides a managed key for encrypting data stored in Amazon S3?

  1. A. AWS Key Management Service (KMS)
  2. B. AWS Certificate Manager
  3. C. AWS Secrets Manager
  4. D. AWS Shield
Answer: A. AWS Key Management Service (KMS)

Q19. When using AWS Lambda with an API Gateway trigger, what is the maximum duration a single invocation can run?

  1. A. 15 minutes
  2. B. 30 minutes
  3. C. 1 hour
  4. D. 5 minutes
Answer: A. 15 minutes

Q20. Network Access Control Lists (NACLs) in a VPC differ from Security Groups because NACLs are:

  1. A. Stateful and operate at the instance level
  2. B. Stateless and operate at the subnet level
  3. C. Stateful and operate at the subnet level
  4. D. Stateless and operate at the instance level
Answer: B. Stateless and operate at the subnet level

Q21. Which AWS service is designed specifically to help you audit, govern, and evaluate configurations of your AWS resources?

  1. A. AWS CloudTrail
  2. B. Amazon GuardDuty
  3. C. AWS Config
  4. D. AWS Trusted Advisor
Answer: C. AWS Config

Q22. What is the primary function of Amazon GuardDuty in an AWS secure architecture?

  1. A. Blocking DDoS attacks at the network edge
  2. B. Managing SSL/TLS certificates automatically
  3. C. Providing intelligent threat detection using machine learning
  4. D. Encrypting database connections at rest
Answer: C. Providing intelligent threat detection using machine learning

Q23. Which AWS service enables governance, compliance, and operational and risk auditing by recording API calls and account activity?

  1. A. AWS CloudTrail
  2. B. AWS CloudWatch
  3. C. Amazon Inspector
  4. D. AWS Shield
Answer: A. AWS CloudTrail

Q24. When implementing a multi-tier web application in AWS, where should the backend database instances typically be placed?

  1. A. Public subnets with internet gateways
  2. B. Private subnets with no direct internet access
  3. C. Directly attached to the Application Load Balancer
  4. D. In the default security group with public IPs
Answer: B. Private subnets with no direct internet access

Q25. Which AWS feature provides hardware-based cryptographic key storage and allows you to generate and control encryption keys easily?

  1. A. AWS KMS
  2. B. AWS CloudHSM
  3. C. AWS Certificate Manager
  4. D. AWS IAM
Answer: B. AWS CloudHSM
