Q1. AWS IAM is used to manage:

  1. A. Billing only
  2. B. Users, groups, roles and their permissions
  3. C. Servers
  4. D. Domains
Answer: B. Users, groups, roles and their permissions

Q2. The AWS root user should be:

  1. A. Used daily
  2. B. Protected with MFA and used only when necessary
  3. C. Shared with the team
  4. D. Deleted
Answer: B. Protected with MFA and used only when necessary

Q3. An IAM role is best used for:

  1. A. Human passwords
  2. B. Giving AWS services/applications temporary permissions
  3. C. Logging in to websites
  4. D. Storing files
Answer: B. Giving AWS services/applications temporary permissions

Q4. Amazon VPC lets you:

  1. A. Send emails
  2. B. Create an isolated virtual network in AWS
  3. C. Host videos
  4. D. Buy domains
Answer: B. Create an isolated virtual network in AWS

Q5. Security groups in a VPC act as:

  1. A. Routers
  2. B. Stateful firewalls for instances
  3. C. Storage
  4. D. Load balancers
Answer: B. Stateful firewalls for instances

Q6. AWS CloudTrail records:

  1. A. Video
  2. B. API activity and account events for auditing
  3. C. Emails
  4. D. Backups
Answer: B. API activity and account events for auditing

Q7. Encryption at rest in S3 protects data:

  1. A. While moving
  2. B. While stored on disks
  3. C. In emails
  4. D. In browsers
Answer: B. While stored on disks

Q8. The principle of least privilege in IAM means:

  1. A. Give admin to everyone
  2. B. Grant only the permissions required to perform a task
  3. C. No permissions at all
  4. D. One policy for all
Answer: B. Grant only the permissions required to perform a task

Q9. An Elastic Load Balancer:

  1. A. Stores data
  2. B. Distributes incoming traffic across multiple targets
  3. C. Encrypts disks
  4. D. Creates users
Answer: B. Distributes incoming traffic across multiple targets

Q10. AWS Lambda is:

  1. A. A database
  2. B. A serverless compute service that runs code in response to events
  3. C. A storage service
  4. D. A network cable
Answer: B. A serverless compute service that runs code in response to events
