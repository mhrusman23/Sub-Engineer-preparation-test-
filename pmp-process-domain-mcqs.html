Q1. A project charter is important because it:

  1. A. Lists all tasks
  2. B. Formally authorises the project and the project manager
  3. C. Sets salaries
  4. D. Closes the project
Answer: B. Formally authorises the project and the project manager

Q2. The critical path of a project is:

  1. A. The cheapest path
  2. B. The longest sequence of dependent activities that determines project duration
  3. C. The riskiest task
  4. D. The first task
Answer: B. The longest sequence of dependent activities that determines project duration

Q3. Earned Value: if CPI is less than 1, the project is:

  1. A. Under budget
  2. B. Over budget
  3. C. Ahead of schedule
  4. D. Finished
Answer: B. Over budget

Q4. A risk register is used to:

  1. A. Record project income
  2. B. Identify, analyse and plan responses to risks
  3. C. List stakeholders
  4. D. Store contracts
Answer: B. Identify, analyse and plan responses to risks

Q5. Change requests in a predictive project should be:

  1. A. Done immediately by anyone
  2. B. Evaluated and approved through integrated change control
  3. C. Ignored
  4. D. Done verbally
Answer: B. Evaluated and approved through integrated change control

Q6. The scope baseline consists of the scope statement, WBS and:

  1. A. Risk register
  2. B. WBS dictionary
  3. C. Charter
  4. D. Budget only
Answer: B. WBS dictionary

Q7. A sprint in Scrum is:

  1. A. A type of meeting
  2. B. A time-boxed iteration, usually 1-4 weeks
  3. C. A document
  4. D. A budget
Answer: B. A time-boxed iteration, usually 1-4 weeks

Q8. The daily stand-up (daily Scrum) is mainly for the team to:

  1. A. Report to the CEO
  2. B. Sync progress and raise impediments
  3. C. Assign salaries
  4. D. Review contracts
Answer: B. Sync progress and raise impediments

Q9. Quality assurance focuses on:

  1. A. Inspecting finished products only
  2. B. Improving processes to prevent defects
  3. C. Testing software
  4. D. Customer complaints
Answer: B. Improving processes to prevent defects

Q10. Lessons learned should be captured:

  1. A. Only at the end
  2. B. Throughout the project
  3. C. Never
  4. D. Only when the project fails
Answer: B. Throughout the project

Q11. In Agile software development, what is the primary purpose of holding a Sprint Retrospective meeting?

  1. A. To inspect the final product features with the customer
  2. B. To assign daily tasks to individual team members
  3. C. To inspect how the team worked and plan improvements for the next sprint
  4. D. To review project budgets and financial forecasts
Answer: C. To inspect how the team worked and plan improvements for the next sprint

Q12. When analyzing project performance using earned value management, a Schedule Performance Index (SPI) of 1.2 indicates that the project is:

  1. A. Progressing faster than scheduled
  2. B. Behind schedule
  3. C. Over budget
  4. D. Under budget
Answer: A. Progressing faster than scheduled

Q13. Which risk response strategy involves shifting the negative impact of a threat along with ownership of the response to a third party?

  1. A. Mitigate
  2. B. Transfer
  3. C. Avoid
  4. D. Accept
Answer: B. Transfer

Q14. During project execution, an independent audit team discovers discrepancies in the reported status of work packages. Which tool or technique is BEST suited to systematically investigate and review adherence to organizational quality policies?

  1. A. Risk Quantification
  2. B. Quality Audit
  3. C. Monte Carlo Simulation
  4. D. Regression Analysis
Answer: B. Quality Audit

Q15. In an Agile project framework, which ceremony is primarily conducted at the end of every iteration to inspect the increment and adapt the product backlog if needed?

  1. A. Sprint Retrospective
  2. B. Daily Standup
  3. C. Sprint Review
  4. D. Backlog Refinement
Answer: C. Sprint Review

Q16. Which of the following documents formally authorizes the existence of a project and provides the project manager with the authority to apply organizational resources to project activities?

  1. A. Project Scope Statement
  2. B. Project Charter
  3. C. WBS Dictionary
  4. D. Resource Management Plan
Answer: B. Project Charter

Q17. Which PMBOK process group involves tracking, reviewing, and regulating project progress and performance?

  1. A. Initiating
  2. B. Planning
  3. C. Monitoring and Controlling
  4. D. Closing
Answer: C. Monitoring and Controlling

Q18. What is the primary output of the Initiating process group that formally authorizes a project?

  1. A. Project Management Plan
  2. B. Project Charter
  3. C. Work Breakdown Structure
  4. D. Scope Baseline
Answer: B. Project Charter

Q19. During which project phase are the majority of the project's budget and resources typically expended?

  1. A. Initiating
  2. B. Planning
  3. C. Executing
  4. D. Closing
Answer: C. Executing

Q20. Which activity is primarily performed during the project Planning process group?

  1. A. Releasing final deliverables
  2. B. Developing the project management plan
  3. C. Obtaining formal stakeholder sign-off
  4. D. Conducting daily stand-up meetings
Answer: B. Developing the project management plan

Q21. What is the primary objective of the Closing process group in project management?

  1. A. Drafting the budget
  2. B. Finalizing all activities and formally completing the project
  3. C. Allocating human resources
  4. D. Identifying project risks
Answer: B. Finalizing all activities and formally completing the project

Q22. Which document outlines how the project scope will be defined, validated, and controlled?

  1. A. Scope Management Plan
  2. B. Work Breakdown Structure
  3. C. Risk Register
  4. D. Quality Management Plan
Answer: A. Scope Management Plan

Q23. During the Project Initiation phase, the project charter is approved. What is the main purpose of the charter?

  1. A. Define the project schedule
  2. B. Authorize the project and assign the project manager
  3. C. Detail the risk register
  4. D. Specify the procurement strategy
Answer: B. Authorize the project and assign the project manager

Q24. Which of the following is NOT a typical output of the Risk Management Planning process?

  1. A. Risk Register
  2. B. Risk Management Plan
  3. C. Risk Breakdown Structure
  4. D. Risk Mitigation Schedule
Answer: D. Risk Mitigation Schedule

Q25. In a predictive project, the Change Control Board reviews a change request that could affect the schedule and cost. Which process group is primarily responsible for approving or rejecting the change?

  1. A. Planning
  2. B. Executing
  3. C. Monitoring & Controlling
  4. D. Closing
Answer: C. Monitoring & Controlling
