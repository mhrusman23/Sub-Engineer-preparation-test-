Q1. A project charter is important because it:

  1. A. Lists all tasks
  2. B. Formally authorises the project and the project manager
  3. C. Sets salaries
  4. D. Closes the project
Answer: B. Formally authorises the project and the project manager

Q2. The critical path of a project is:

  1. A. The cheapest path
  2. B. The longest sequence of dependent activities that determines project duration
  3. C. The riskiest task
  4. D. The first task
Answer: B. The longest sequence of dependent activities that determines project duration

Q3. Earned Value: if CPI is less than 1, the project is:

  1. A. Under budget
  2. B. Over budget
  3. C. Ahead of schedule
  4. D. Finished
Answer: B. Over budget

Q4. A risk register is used to:

  1. A. Record project income
  2. B. Identify, analyse and plan responses to risks
  3. C. List stakeholders
  4. D. Store contracts
Answer: B. Identify, analyse and plan responses to risks

Q5. Change requests in a predictive project should be:

  1. A. Done immediately by anyone
  2. B. Evaluated and approved through integrated change control
  3. C. Ignored
  4. D. Done verbally
Answer: B. Evaluated and approved through integrated change control

Q6. The scope baseline consists of the scope statement, WBS and:

  1. A. Risk register
  2. B. WBS dictionary
  3. C. Charter
  4. D. Budget only
Answer: B. WBS dictionary

Q7. A sprint in Scrum is:

  1. A. A type of meeting
  2. B. A time-boxed iteration, usually 1-4 weeks
  3. C. A document
  4. D. A budget
Answer: B. A time-boxed iteration, usually 1-4 weeks

Q8. The daily stand-up (daily Scrum) is mainly for the team to:

  1. A. Report to the CEO
  2. B. Sync progress and raise impediments
  3. C. Assign salaries
  4. D. Review contracts
Answer: B. Sync progress and raise impediments

Q9. Quality assurance focuses on:

  1. A. Inspecting finished products only
  2. B. Improving processes to prevent defects
  3. C. Testing software
  4. D. Customer complaints
Answer: B. Improving processes to prevent defects

Q10. Lessons learned should be captured:

  1. A. Only at the end
  2. B. Throughout the project
  3. C. Never
  4. D. Only when the project fails
Answer: B. Throughout the project
