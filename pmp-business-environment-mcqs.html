Q1. The Business Environment domain links the project to:

  1. A. Only the team
  2. B. Organisational strategy and goals
  3. C. Only the budget
  4. D. Only suppliers
Answer: B. Organisational strategy and goals

Q2. Project governance provides:

  1. A. Daily tasks
  2. B. The framework for decision-making and oversight
  3. C. Office space
  4. D. Software licenses
Answer: B. The framework for decision-making and oversight

Q3. A benefit realisation plan ensures:

  1. A. The project finishes early
  2. B. The project's benefits are identified, delivered and measured
  3. C. Costs are hidden
  4. D. Risks are ignored
Answer: B. The project's benefits are identified, delivered and measured

Q4. Compliance requirements in a project may include:

  1. A. Only internal rules
  2. B. Laws, regulations and standards the project must follow
  3. C. Team preferences
  4. D. Meeting times
Answer: B. Laws, regulations and standards the project must follow

Q5. When the organisation's strategy changes, the project manager should:

  1. A. Ignore it
  2. B. Assess the impact on the project and align with the new strategy
  3. C. Stop all work forever
  4. D. Blame the sponsor
Answer: B. Assess the impact on the project and align with the new strategy

Q6. External factors such as new market trends are handled by:

  1. A. Avoiding all change
  2. B. Scanning the environment and adapting the project
  3. C. Closing the project
  4. D. Hiring more staff
Answer: B. Scanning the environment and adapting the project

Q7. The project sponsor's main role is to:

  1. A. Write the code
  2. B. Champion the project and secure resources and support
  3. C. Test the product
  4. D. Take meeting notes
Answer: B. Champion the project and secure resources and support

Q8. Organisational change from a project succeeds best when:

  1. A. It is a surprise
  2. B. Stakeholders are prepared and supported through the change
  3. C. Only managers know
  4. D. Training is skipped
Answer: B. Stakeholders are prepared and supported through the change

Q9. A PMO (Project Management Office) typically:

  1. A. Replaces all project managers
  2. B. Supports projects with standards, methods and resources
  3. C. Owns the company
  4. D. Does the testing
Answer: B. Supports projects with standards, methods and resources

Q10. Value delivery means the project should:

  1. A. Finish tasks only
  2. B. Produce outcomes that benefit the organisation and customers
  3. C. Spend the whole budget
  4. D. Avoid stakeholders
Answer: B. Produce outcomes that benefit the organisation and customers
