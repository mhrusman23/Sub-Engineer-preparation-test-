Q1. The Business Environment domain links the project to:

  1. A. Only the team
  2. B. Organisational strategy and goals
  3. C. Only the budget
  4. D. Only suppliers
Answer: B. Organisational strategy and goals

Q2. Project governance provides:

  1. A. Daily tasks
  2. B. The framework for decision-making and oversight
  3. C. Office space
  4. D. Software licenses
Answer: B. The framework for decision-making and oversight

Q3. A benefit realisation plan ensures:

  1. A. The project finishes early
  2. B. The project's benefits are identified, delivered and measured
  3. C. Costs are hidden
  4. D. Risks are ignored
Answer: B. The project's benefits are identified, delivered and measured

Q4. Compliance requirements in a project may include:

  1. A. Only internal rules
  2. B. Laws, regulations and standards the project must follow
  3. C. Team preferences
  4. D. Meeting times
Answer: B. Laws, regulations and standards the project must follow

Q5. When the organisation's strategy changes, the project manager should:

  1. A. Ignore it
  2. B. Assess the impact on the project and align with the new strategy
  3. C. Stop all work forever
  4. D. Blame the sponsor
Answer: B. Assess the impact on the project and align with the new strategy

Q6. External factors such as new market trends are handled by:

  1. A. Avoiding all change
  2. B. Scanning the environment and adapting the project
  3. C. Closing the project
  4. D. Hiring more staff
Answer: B. Scanning the environment and adapting the project

Q7. The project sponsor's main role is to:

  1. A. Write the code
  2. B. Champion the project and secure resources and support
  3. C. Test the product
  4. D. Take meeting notes
Answer: B. Champion the project and secure resources and support

Q8. Organisational change from a project succeeds best when:

  1. A. It is a surprise
  2. B. Stakeholders are prepared and supported through the change
  3. C. Only managers know
  4. D. Training is skipped
Answer: B. Stakeholders are prepared and supported through the change

Q9. A PMO (Project Management Office) typically:

  1. A. Replaces all project managers
  2. B. Supports projects with standards, methods and resources
  3. C. Owns the company
  4. D. Does the testing
Answer: B. Supports projects with standards, methods and resources

Q10. Value delivery means the project should:

  1. A. Finish tasks only
  2. B. Produce outcomes that benefit the organisation and customers
  3. C. Spend the whole budget
  4. D. Avoid stakeholders
Answer: B. Produce outcomes that benefit the organisation and customers

Q11. What is the main function of a Project Management Office (PMO) in an enterprise?

  1. A. Writing all project code
  2. B. Providing governance, standardization, and support across organizational projects
  3. C. Approving team vacation requests
  4. D. Replacing the project manager on daily tasks
Answer: B. Providing governance, standardization, and support across organizational projects

Q12. How should a project manager respond to newly introduced government environmental regulations that affect the project scope?

  1. A. Ignore them until project closure
  2. B. Assess their impact and update the compliance and project plans accordingly
  3. C. Cancel the project immediately
  4. D. Ask the development team to bypass the laws
Answer: B. Assess their impact and update the compliance and project plans accordingly

Q13. When assessing the external business environment, a project manager analyzes macroeconomic trends primarily to:

  1. A. Determine team member salaries
  2. B. Identify potential opportunities and threats that could impact project viability
  3. C. Choose the project management software
  4. D. Schedule daily stand-up meetings
Answer: B. Identify potential opportunities and threats that could impact project viability

Q14. Which artifact outlines how and when the benefits delivered by the project will be measured and sustained?

  1. A. Project Charter
  2. B. Benefits Realization Plan
  3. C. Risk Register
  4. D. Work Breakdown Structure
Answer: B. Benefits Realization Plan

Q15. What is the primary objective of organizational change management (OCM) within a project lifecycle?

  1. A. To reduce the overall budget
  2. B. To ensure smooth adoption and sustained use of the project's deliverables by stakeholders
  3. C. To increase the speed of software coding
  4. D. To eliminate all project risks
Answer: B. To ensure smooth adoption and sustained use of the project's deliverables by stakeholders

Q16. If a project's expected outcomes no longer align with the evolving corporate vision, the most appropriate governance action is to:

  1. A. Proceed blindly with the original baseline
  2. B. Review the project alignment with leadership and consider re-evaluating or terminating the project
  3. C. Increase the project budget to compensate
  4. D. Hide the misalignment from stakeholders
Answer: B. Review the project alignment with leadership and consider re-evaluating or terminating the project

Q17. Which document formally authorizes the existence of a project and gives the project manager authority to apply organizational resources?

  1. A. Project Scope Statement
  2. B. Project Charter
  3. C. Business Case
  4. D. Benefits Management Plan
Answer: B. Project Charter

Q18. What primary tool is used to evaluate the financial feasibility of a project by calculating the rate where net present value equals zero?

  1. A. Payback Period
  2. B. Benefit-Cost Ratio
  3. C. Internal Rate of Return
  4. D. Return on Investment
Answer: C. Internal Rate of Return

Q19. During project execution, a major shift in trade regulations occurs. What should the project manager do first?

  1. A. Immediately alter project deliverables to match the new rules
  2. B. Assess the impact of the regulation change on project constraints
  3. C. Ignore the change if it was not in the original scope
  4. D. Close the project due to external risks
Answer: B. Assess the impact of the regulation change on project constraints

Q20. Which organizational structure gives the project manager the highest level of authority and control over project resources?

  1. A. Functional
  2. B. Weak Matrix
  3. C. Balanced Matrix
  4. D. Project-oriented
Answer: D. Project-oriented

Q21. What is the primary objective of implementing project governance?

  1. A. To handle day-to-day technical task execution
  2. B. To provide a consistent framework for steering and controlling project work
  3. C. To eliminate all possible project risks
  4. D. To reduce the need for stakeholder communication
Answer: B. To provide a consistent framework for steering and controlling project work

Q22. How does organizational culture typically impact project management success?

  1. A. It has no bearing on technical deliverables
  2. B. It dictates how stakeholders communicate and accept change
  3. C. It automatically fixes budget overruns
  4. D. It replaces the need for a formal risk register
Answer: B. It dictates how stakeholders communicate and accept change

Q23. Which of the following best describes how a project manager should handle newly enforced environmental legislation affecting project deliverables?

  1. A. Ignore the regulations until the project concludes
  2. B. Evaluate the impact and update compliance plans accordingly
  3. C. Cancel the project immediately without review
  4. D. Hide the new requirements from the project sponsor
Answer: B. Evaluate the impact and update compliance plans accordingly

Q24. What is the primary purpose of conducting a benefits realization analysis after project completion?

  1. A. To calculate individual team member bonuses
  2. B. To verify whether the intended business value and outcomes were actually achieved
  3. C. To increase the total budget for future initiatives
  4. D. To eliminate the need for project documentation
Answer: B. To verify whether the intended business value and outcomes were actually achieved

Q25. When an internal organizational restructuring alters reporting lines mid-project, what is the best immediate action for the project manager?

  1. A. Stop all project work until leadership stabilizes
  2. B. Update the stakeholder register and communication management plan to reflect new authorities
  3. C. Refuse to acknowledge the structural change
  4. D. Dismiss the project sponsor
Answer: B. Update the stakeholder register and communication management plan to reflect new authorities
