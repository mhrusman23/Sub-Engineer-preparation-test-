Q1. The AAA framework stands for:

  1. A. Access, Audit, Allow
  2. B. Authentication, Authorization, Accounting
  3. C. Automatic Address Assignment
  4. D. Advanced Anti-virus Access
Answer: B. Authentication, Authorization, Accounting

Q2. A firewall's main function is to:

  1. A. Speed up the network
  2. B. Control traffic based on security rules
  3. C. Store data
  4. D. Assign addresses
Answer: B. Control traffic based on security rules

Q3. Which is a strong password practice?

  1. A. Using your birthday
  2. B. Long, unique passwords with mixed characters and MFA
  3. C. Reusing one password
  4. D. Sharing passwords
Answer: B. Long, unique passwords with mixed characters and MFA

Q4. A VPN provides:

  1. A. Free internet
  2. B. An encrypted tunnel over a public network
  3. C. Faster downloads
  4. D. More storage
Answer: B. An encrypted tunnel over a public network

Q5. Port security on a switch can:

  1. A. Add more ports
  2. B. Limit which MAC addresses can use a port
  3. C. Increase speed
  4. D. Disable the switch
Answer: B. Limit which MAC addresses can use a port

Q6. DHCP snooping protects against:

  1. A. Viruses
  2. B. Rogue DHCP servers
  3. C. Power failure
  4. D. Slow Wi-Fi
Answer: B. Rogue DHCP servers

Q7. The principle of least privilege means users should have:

  1. A. All access
  2. B. Only the access needed for their job
  3. C. No access
  4. D. Admin rights
Answer: B. Only the access needed for their job

Q8. 802.1X is used for:

  1. A. Routing
  2. B. Port-based network access authentication
  3. C. Printing
  4. D. Backups
Answer: B. Port-based network access authentication

Q9. A man-in-the-middle attack is when an attacker:

  1. A. Breaks a cable
  2. B. Secretly intercepts communication between two parties
  3. C. Steals a laptop
  4. D. Sends spam
Answer: B. Secretly intercepts communication between two parties

Q10. Regular software updates (patching) are important to:

  1. A. Use more storage
  2. B. Fix known security vulnerabilities
  3. C. Change the interface
  4. D. Slow down attackers' computers
Answer: B. Fix known security vulnerabilities

Q11. In the context of wireless network security, which protocol introduced robust encryption utilizing the Advanced Encryption Standard (AES) to replace vulnerable WEP and older TKIP methods?

  1. A. WPA2
  2. B. WPS
  3. C. WEP
  4. D. WPA
Answer: A. WPA2

Q12. What is the primary purpose of implementing Access Control Lists (ACLs) on router interfaces?

  1. A. To compress packet payloads for faster routing
  2. B. To filter network traffic based on specified rules and criteria
  3. C. To automatically assign IP addresses to hosts
  4. D. To translate private IP addresses to public IP addresses
Answer: B. To filter network traffic based on specified rules and criteria

Q13. Which security device feature inspects stateful traffic flows and can drop packets that do not belong to an established, legitimate connection?

  1. A. Hub
  2. B. Stateful Firewall
  3. C. Unmanaged Switch
  4. D. Repeater
Answer: B. Stateful Firewall

Q14. Which protocol is primarily utilized to secure remote administrative command-line access to network devices by encrypting the entire management session?

  1. A. Telnet
  2. B. SSH
  3. C. HTTP
  4. D. SNMPv1
Answer: B. SSH

Q15. What is the main function of an Intrusion Prevention System (IPS) when deployed inline on a network?

  1. A. To only log alerts without altering traffic
  2. B. To actively block or reset detected malicious traffic streams
  3. C. To increase available network bandwidth
  4. D. To balance workloads across multiple servers
Answer: B. To actively block or reset detected malicious traffic streams

Q16. Which AAA component is responsible for keeping track of the specific network resource consumption and commands executed by a user?

  1. A. Authentication
  2. B. Authorization
  3. C. Accounting
  4. D. Auditing
Answer: C. Accounting

Q17. Which wireless security protocol introduced robust encryption utilizing the Advanced Encryption Standard (AES) to replace vulnerable WEP and TKIP systems?

  1. A. WPA
  2. B. WEP2
  3. C. WPA2
  4. D. WPS
Answer: C. WPA2

Q18. Which secure protocol should network administrators utilize instead of Telnet when managing router and switch command-line interfaces remotely?

  1. A. HTTP
  2. B. SNMPv1
  3. C. SSH
  4. D. TFTP
Answer: C. SSH

Q19. What is the primary role of an Intrusion Prevention System (IPS) compared to a passive Intrusion Detection System (IDS)?

  1. A. It only logs network anomalies without taking action
  2. B. It actively blocks or drops packets identified as malicious
  3. C. It encrypts all traffic passing through the core router
  4. D. It dynamically updates switch MAC address tables
Answer: B. It actively blocks or drops packets identified as malicious

Q20. Which mechanism is used by a switch to mitigate DHCP spoofing and rogue DHCP server attacks on local network segments?

  1. A. Port Security
  2. B. DHCP Snooping
  3. C. Dynamic ARP Inspection
  4. D. IP Source Guard
Answer: B. DHCP Snooping

Q21. What is the primary purpose of configuring standard or extended Access Control Lists (ACLs) on a Cisco router interface?

  1. A. To compress data packets for faster WAN transmission
  2. B. To filter network traffic based on specified criteria and rules
  3. C. To dynamically assign IP addresses to connecting clients
  4. D. To automatically route traffic along the shortest path
Answer: B. To filter network traffic based on specified criteria and rules

Q22. Which command displays the current NAT translation table on a Cisco router?

  1. A. show ip nat statistics
  2. B. show ip nat translations
  3. C. show nat translations
  4. D. show ip nat details
Answer: B. show ip nat translations

Q23. Which ACL type is most appropriate for permitting only management traffic from a specific subnet to a router?

  1. A. Standard ACL
  2. B. Extended ACL
  3. C. Dynamic ACL
  4. D. Access group
Answer: B. Extended ACL

Q24. In a Cisco ASA, which logging facility should be enabled to send syslog messages to an external server?

  1. A. logging enable
  2. B. logging host
  3. C. logging trap
  4. D. logging buffer
Answer: B. logging host

Q25. Which feature of an Intrusion Prevention System (IPS) examines packet contents for malicious patterns?

  1. A. Stateful inspection
  2. B. Deep packet inspection
  3. C. Port security
  4. D. MAC filtering
Answer: B. Deep packet inspection
