Q1. What is the decimal equivalent of the binary number 1010?

  1. A. 8
  2. B. 10
  3. C. 12
  4. D. 14
Answer: B. 10

Q2. Which cryptographic algorithm is a symmetric block cipher that supports key sizes of 128, 192, and 256 bits?

  1. A. RSA
  2. B. Diffie-Hellman
  3. C. AES
  4. D. SHA-256
Answer: C. AES

Q3. Which data structure operates on the Last-In, First-Out (LIFO) principle?

  1. A. Queue
  2. B. Stack
  3. C. Array
  4. D. Linked List
Answer: B. Stack

Q4. Which SQL command is used to permanently save changes made in the current transaction?

  1. A. ROLLBACK
  2. B. COMMIT
  3. C. SAVEPOINT
  4. D. REVOKE
Answer: B. COMMIT

Q9. What is the main purpose of a DNS server in networking?
