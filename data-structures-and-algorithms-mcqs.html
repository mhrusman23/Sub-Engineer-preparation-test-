Q1. Which data structure follows the LIFO principle?

  1. A. Queue
  2. B. Stack
  3. C. Linked list
  4. D. Array
Answer: B. Stack

Q2. Which data structure follows the FIFO principle?

  1. A. Stack
  2. B. Tree
  3. C. Graph
  4. D. Queue
Answer: D. Queue

Q3. The time complexity of binary search on a sorted array is:

  1. A. O(n)
  2. B. O(log n)
  3. C. O(1)
  4. D. O(n log n)
Answer: B. O(log n)

Q4. The worst-case time complexity of bubble sort is:

  1. A. O(n)
  2. B. O(n^2)
  3. C. O(1)
  4. D. O(log n)
Answer: B. O(n^2)

Q5. A binary tree node has at most how many children?

  1. A. 2
  2. B. 4
  3. C. 1
  4. D. 3
Answer: A. 2

Q6. Which traversal of a binary search tree gives sorted order?

  1. A. Inorder
  2. B. Postorder
  3. C. Level order
  4. D. Preorder
Answer: A. Inorder

Q7. Accessing an array element by index takes:

  1. A. O(1)
  2. B. O(n^2)
  3. C. O(log n)
  4. D. O(n)
Answer: A. O(1)

Q8. A graph traversal that uses a queue is:

  1. A. Binary search
  2. B. Depth-first search
  3. C. Breadth-first search
  4. D. Merge sort
Answer: C. Breadth-first search

Q9. Which sorting algorithm uses the divide-and-conquer approach?

  1. A. Insertion sort
  2. B. Bubble sort
  3. C. Merge sort
  4. D. Selection sort
Answer: C. Merge sort

Q10. A hash table gives average lookup time of:

  1. A. O(1)
  2. B. O(n)
  3. C. O(n^2)
  4. D. O(log n)
Answer: A. O(1)

Q11. Which data structure operates on a Last-In, First-Out (LIFO) basis?

  1. A. Queue
  2. B. Stack
  3. C. Array
  4. D. Tree
Answer: B. Stack

Q12. What is the worst-case time complexity of the QuickSort algorithm?

  1. A. O(n log n)
  2. B. O(n)
  3. C. O(n^2)
  4. D. O(log n)
Answer: C. O(n^2)

Q13. Which specific data structure is most efficiently utilized to implement a recursive function call stack in a computer system?

  1. A. Queue
  2. B. Stack
  3. C. Priority Queue
  4. D. Linked List
Answer: B. Stack

Q14. In the context of asymptotic notation, what does Big-O notation primarily measure?

  1. A. Exact execution time in milliseconds
  2. B. The upper bound of algorithm growth rate
  3. C. The exact memory consumed in bytes
  4. D. The lower bound of resource utilization
Answer: B. The upper bound of algorithm growth rate

Q15. Which graph traversal algorithm systematically explores neighbor nodes level by level using a queue?

  1. A. Depth-First Search
  2. B. Breadth-First Search
  3. C. Dijkstra's Algorithm
  4. D. Binary Search
Answer: B. Breadth-First Search

Q16. What is the primary structural property of a Min-Heap binary tree?

  1. A. Every parent node is greater than or equal to its children
  2. B. Every parent node is less than or equal to its children
  3. C. Left child is always greater than the right child
  4. D. All leaves are at different depths
Answer: B. Every parent node is less than or equal to its children

Q17. What is the worst-case time complexity of standard insertion sort when sorting an array in reverse order?

  1. A. O(n log n)
  2. B. O(n)
  3. C. O(n^2)
  4. D. O(1)
Answer: C. O(n^2)

Q18. Which algorithmic technique is commonly applied in graphs to find a linear ordering of vertices such that for every directed edge uv, u comes before v?

  1. A. A) Topological sort
  2. B. B) Binary search
  3. C. C) Bubble sort
  4. D. D) In-order traversal
Answer: A. A) Topological sort

Q19. What is the primary factor measured by the time complexity function of a given sorting algorithm?

  1. A. A) Running time execution as a growth function of input size
  2. B. B) Total physical memory consumed during execution
  3. C. C) Number of lines of source code compiled
  4. D. D) Network bandwidth utilized by the processor
Answer: A. A) Running time execution as a growth function of input size

Q20. Which of the following is traditionally NOT considered a standard structural variation of a queue data structure?

  1. A. A) Circular queue
  2. B. B) Priority queue
  3. C. C) Single ended queue
  4. D. D) Double ended queue
Answer: C. C) Single ended queue

Q21. Which of the following data structures is most commonly used for organizing and indexing data in external memory storage systems?

  1. A. A) AVL tree
  2. B. B) B-tree
  3. C. C) Red-black tree
  4. D. D) Binary search tree
Answer: B. B) B-tree

Q22. Which sorting algorithm consistently achieves an optimal time complexity of O(n log n) in both worst and average cases by repeatedly dividing the list into halves?

  1. A. A) Insertion Sort
  2. B. B) Selection Sort
  3. C. C) Merge Sort
  4. D. D) Bubble Sort
Answer: C. C) Merge Sort

Q23. In a Min-Heap data structure, the key stored at each node is:

  1. A. A) Greater than or equal to the keys of its children
  2. B. B) Less than or equal to the keys of its children
  3. C. C) Exactly equal to the sum of its children's keys
  4. D. D) Unrelated to the keys of its children
Answer: B. B) Less than or equal to the keys of its children

Q24. Which algorithm is commonly used to find the shortest path from a single source vertex to all other vertices in a weighted graph with non-negative edge weights?

  1. A. A) Kruskal's algorithm
  2. B. B) Prim's algorithm
  3. C. C) Dijkstra's algorithm
  4. D. D) Topological sort
Answer: C. C) Dijkstra's algorithm

Q25. What is the worst-case time complexity of standard QuickSort when the pivot chosen is consistently the smallest or largest element?

  1. A. A) O(n log n)
  2. B. B) O(n)
  3. C. C) O(n^2)
  4. D. D) O(log n)
Answer: C. C) O(n^2)
