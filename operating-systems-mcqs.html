Q1. Which of these is an operating system?

  1. A. Chrome
  2. B. Linux
  3. C. Python
  4. D. Oracle
Answer: B. Linux

Q2. The core part of an operating system is the:

  1. A. Compiler
  2. B. Browser
  3. C. Kernel
  4. D. Shell only
Answer: C. Kernel

Q3. A process in execution waiting for the CPU is in the:

  1. A. New state only
  2. B. Blocked forever
  3. C. Ready state
  4. D. Terminated state
Answer: C. Ready state

Q4. Which scheduling algorithm gives each process a fixed time slice?

  1. A. Priority only
  2. B. Shortest job first
  3. C. Round robin
  4. D. FCFS
Answer: C. Round robin

Q5. A deadlock occurs when processes:

  1. A. Share a printer politely
  2. B. Finish quickly
  3. C. Use no memory
  4. D. Wait for each other indefinitely
Answer: D. Wait for each other indefinitely

Q6. Virtual memory uses a part of the:

  1. A. CPU registers only
  2. B. Monitor
  3. C. Disk as extended memory
  4. D. Keyboard
Answer: C. Disk as extended memory

Q7. The Unix command to list files in a directory is:

  1. A. ls
  2. B. dir only
  3. C. list
  4. D. show
Answer: A. ls

Q8. Paging is a technique used in:

  1. A. Printing
  2. B. Memory management
  3. C. File compression
  4. D. Networking
Answer: B. Memory management

Q9. A thread is the smallest unit of:

  1. A. Display
  2. B. Disk storage
  3. C. Network speed
  4. D. CPU execution
Answer: D. CPU execution

Q10. The command-line interface of an OS is often called the:

  1. A. Firmware
  2. B. Driver
  3. C. Shell
  4. D. Kernel
Answer: C. Shell

Q11. Which of the following is an example of System Software?

  1. A. Microsoft Word
  2. B. Adobe Photoshop
  3. C. Linux Operating System
  4. D. Google Chrome
Answer: C. Linux Operating System

Q12. Which scheduling algorithm executes processes in the exact order of their arrival?

  1. A. Round Robin
  2. B. Shortest Job First
  3. C. First-Come, First-Served (FCFS)
  4. D. Priority Scheduling
Answer: C. First-Come, First-Served (FCFS)

Q13. Which type of hypervisor runs directly on the host hardware without an underlying operating system?

  1. A. Type-1 Hypervisor
  2. B. Type-2 Hypervisor
  3. C. Hosted Hypervisor
  4. D. Application Hypervisor
Answer: A. Type-1 Hypervisor

Q14. Which memory management scheme allocates physical memory dynamically based on variable-sized blocks?

  1. A. Paging
  2. B. Segmentation
  3. C. Fixed Partitioning
  4. D. Caching
Answer: B. Segmentation

Q15. What is the primary function of an Operating System?

  1. A. Word processing
  2. B. Managing computer hardware and software resources
  3. C. Designing web pages
  4. D. Compiling source code
Answer: B. Managing computer hardware and software resources

Q16. Which scheduling algorithm assigns a fixed time slice to each process in a cyclic order?

  1. A. First-Come, First-Served
  2. B. Shortest Job First
  3. C. Round Robin
  4. D. Priority Scheduling
Answer: C. Round Robin

Q17. Which scheduling algorithm can cause starvation of processes with longer execution times?

  1. A. First-Come, First-Served
  2. B. Round Robin
  3. C. Shortest Job First
  4. D. Multilevel Queue
Answer: C. Shortest Job First

Q18. What is the primary purpose of the Banker's Algorithm in an operating system?

  1. A. Process synchronization
  2. B. Deadlock avoidance
  3. C. Memory allocation
  4. D. CPU scheduling
Answer: B. Deadlock avoidance

Q19. What is the term for a situation where a low-priority process holds a resource that a high-priority process needs, but a medium-priority process preempts the CPU?

  1. A. Starvation
  2. B. Priority inversion
  3. C. Race condition
  4. D. Thrashing
Answer: B. Priority inversion

Q20. Which page replacement algorithm suffers from Belady's Anomaly, where increasing the number of page frames results in an increase in page faults?

  1. A. FIFO
  2. B. LRU
  3. C. Optimal
  4. D. LFU
Answer: A. FIFO

Q21. Which of the following conditions is NOT required for a deadlock to occur according to Coffman's conditions?

  1. A. Mutual exclusion
  2. B. Hold and wait
  3. C. Preemption
  4. D. Circular wait
Answer: C. Preemption

Q22. Which file allocation method supports both direct and sequential access efficiently while preventing external fragmentation?

  1. A. Contiguous allocation
  2. B. Linked allocation
  3. C. Indexed allocation
  4. D. Cluster allocation
Answer: C. Indexed allocation

Q23. In semaphore implementation, which of the following operations is atomic and decreases the semaphore value?

  1. A. Signal
  2. B. Wait
  3. C. Release
  4. D. Unlock
Answer: B. Wait

Q24. In a real-time operating system, what must be guaranteed for any critical task execution?

  1. A. It must be serviced within its specified deadline period
  2. B. It must be executed using a round-robin time quantum
  3. C. It must have the lowest priority in the system queue
  4. D. It must bypass the kernel entirely for faster speeds
Answer: A. It must be serviced within its specified deadline period

Q25. During the execution lifecycle of a standard process, what are the two primary types of execution bursts it alternates between?

  1. A. CPU burst and I/O burst
  2. B. Memory burst and Cache burst
  3. C. Read burst and Write burst
  4. D. User burst and Kernel burst
Answer: A. CPU burst and I/O burst
