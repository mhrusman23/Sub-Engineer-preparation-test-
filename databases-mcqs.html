Q1. SQL stands for:

  1. A. Structured Query Language
  2. B. Standard Question List
  3. C. Simple Query Logic
  4. D. Sequential Query Language
Answer: A. Structured Query Language

Q2. Which SQL command retrieves data from a table?

  1. A. INSERT
  2. B. DELETE
  3. C. UPDATE
  4. D. SELECT
Answer: D. SELECT

Q3. A primary key must be:

  1. A. Optional
  2. B. Repeated
  3. C. Always text
  4. D. Unique and not null
Answer: D. Unique and not null

Q4. Which SQL clause filters rows?

  1. A. ORDER BY
  2. B. FROM
  3. C. WHERE
  4. D. GROUP BY
Answer: C. WHERE

Q5. Which normal form removes partial dependency?

  1. A. Second normal form
  2. B. First normal form
  3. C. Zero normal form
  4. D. Boolean normal form
Answer: A. Second normal form

Q6. A foreign key is used to:

  1. A. Encrypt data
  2. B. Delete a table
  3. C. Link two tables
  4. D. Sort records
Answer: C. Link two tables

Q7. ACID in databases stands for atomicity, consistency, isolation and:

  1. A. Authority
  2. B. Accuracy
  3. C. Availability
  4. D. Durability
Answer: D. Durability

Q8. Which SQL command removes a table completely?

  1. A. REMOVE
  2. B. CLEAR
  3. C. DELETE
  4. D. DROP TABLE
Answer: D. DROP TABLE

Q9. The JOIN operation is used to:

  1. A. Delete duplicates
  2. B. Combine rows from two or more tables
  3. C. Rename a table
  4. D. Create an index only
Answer: B. Combine rows from two or more tables

Q10. Which of these is a NoSQL database?

  1. A. PostgreSQL
  2. B. MySQL
  3. C. Oracle Database
  4. D. MongoDB
Answer: D. MongoDB

Q11. What does ACID stand for in the context of database management systems?

  1. A. Atomicity, Consistency, Isolation, Durability
  2. B. Access, Control, Integrity, Data
  3. C. Automation, Computation, Indexing, Distribution
  4. D. Association, Clustering, Identification, Deployment
Answer: A. Atomicity, Consistency, Isolation, Durability

Q12. Which Normal Form in relational databases eliminates transitive dependencies?

  1. A. First Normal Form
  2. B. Second Normal Form
  3. C. Third Normal Form
  4. D. Fourth Normal Form
Answer: C. Third Normal Form

Q13. Which SQL command is used to permanently save changes made during the current transaction?

  1. A. ROLLBACK
  2. B. COMMIT
  3. C. SAVEPOINT
  4. D. REVOKE
Answer: B. COMMIT

Q14. In a relational database, what uniquely identifies each record in a table?

  1. A. Foreign Key
  2. B. Primary Key
  3. C. Composite Key
  4. D. Candidate Key
Answer: B. Primary Key

Q15. What does SQL stand for in database management?

  1. A. Simple Query Language
  2. B. Structured Query Language
  3. C. System Quality Language
  4. D. Sequential Query Logic
Answer: B. Structured Query Language

Q16. Which normalization form removes partial functional dependencies in a database?

  1. A. 1NF
  2. B. 2NF
  3. C. 3NF
  4. D. BCNF
Answer: B. 2NF

Q17. Which SQL clause is used to filter records that fulfill a specified condition after an aggregation?

  1. A. WHERE
  2. B. HAVING
  3. C. FILTER
  4. D. GROUP BY
Answer: B. HAVING

Q18. What does the 'ACID' property 'Atomicity' mean in database management systems?

  1. A. Transactions must follow database safety rules
  2. B. Transactions are all-or-nothing operations
  3. C. Concurrent transactions do not interfere
  4. D. Committed data is permanently saved
Answer: B. Transactions are all-or-nothing operations
