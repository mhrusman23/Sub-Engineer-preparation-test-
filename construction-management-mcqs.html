Construction Management MCQs (Diploma Civil)

Free MCQs with answers for Construction Management. 16 questions in 2 chapter tests are in the app; all are shown here.

Q1. CPM stands for critical path:

  1. A. Measure
  2. B. Method
  3. C. Model
  4. D. Management
Answer: B. Method

Q2. The critical path is the:

  1. A. Easiest path
  2. B. Longest path through the network
  3. C. Shortest path
  4. D. Cheapest path
Answer: B. Longest path through the network

Q3. A Gantt chart shows project activities against:

  1. A. Cost only
  2. B. Quality only
  3. C. Labour age
  4. D. Time
Answer: D. Time

Q4. Float or slack is the time an activity can be delayed without delaying:

  1. A. The bill
  2. B. The weather
  3. C. Only labour
  4. D. The project
Answer: D. The project

Q5. Which contract type fixes the price for the whole work?

  1. A. Lump sum contract
  2. B. Cost plus contract
  3. C. Time and material only
  4. D. Unit rate only
Answer: A. Lump sum contract

Q6. The tender is a:

  1. A. Formal offer to do work at a price
  2. B. Drawing
  3. C. Site visit
  4. D. Final payment
Answer: A. Formal offer to do work at a price

Q7. A site safety plan mainly aims to prevent:

  1. A. Delays in payment
  2. B. Weather changes
  3. C. Accidents and injuries
  4. D. Cost increases
Answer: C. Accidents and injuries

Q8. Quality control during construction ensures:

  1. A. More labour
  2. B. Work meets specifications
  3. C. Slower progress
  4. D. Higher cost
Answer: B. Work meets specifications

Q9. Resource levelling is used to:

  1. A. Hide delays
  2. B. Increase cost
  3. C. Smooth resource demand over time
  4. D. Reduce quality
Answer: C. Smooth resource demand over time

Q10. PERT uses three time estimates: optimistic, most likely and:

  1. A. Actual
  2. B. Standard
  3. C. Pessimistic
  4. D. Average
Answer: C. Pessimistic

Q11. Which construction document officially invites contractors to submit their pricing and project execution proposals?

  1. A. Work order
  2. B. Notice inviting tender
  3. C. Completion certificate
  4. D. Measurement book
Answer: B. Notice inviting tender

Q12. What is the primary purpose of maintaining a Hindrance Register on a construction site?

  1. A. Recording daily weather updates
  2. B. Tracking material delivery weights
  3. C. Documenting delays beyond the contractor's control
  4. D. Calculating weekly worker wages
Answer: C. Documenting delays beyond the contractor's control

Q13. Under which contract format does the owner pay the contractor for actual measured quantities at pre-agreed unit rates?

  1. A. Lump sum contract
  2. B. Cost plus fee contract
  3. C. Item rate contract
  4. D. Turnkey contract
Answer: C. Item rate contract

Q14. Which specific chart illustrates the daily availability, allocation, and requirement of construction equipment over a project timeline?

  1. A. Resource histogram
  2. B. Org chart
  3. C. Network diagram
  4. D. Control chart
Answer: A. Resource histogram

Q15. What does crashing a construction network schedule primarily involve?

  1. A. Extending project duration to save money
  2. B. Reducing duration by adding extra resources
  3. C. Stopping work temporarily due to safety risks
  4. D. Lowering material quality to cut expenses
Answer: B. Reducing duration by adding extra resources

Q16. Which official site document records all day-to-day progress, workforce count, and material receipts?

  1. A. Site order book
  2. B. Measurement book
  3. C. Site daily diary
  4. D. Indentation form
Answer: C. Site daily diary
