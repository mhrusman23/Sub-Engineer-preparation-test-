Q1. If R.B =6 degree 45 minutes SE find WCB=?

  1. A. 173-15
  2. B. 175-15
  3. C. 176-15
  4. D. 174-15
Answer: A. 173-15

Q2. The first reading of staff at a point or bench mark is called....

  1. A. Back sight
  2. B. inter sight
  3. C. fore sight
  4. D. any one
Answer: A. Back sight

Q3. The instrument having such a telescope with three horizontal cross hairs is called....

  1. A. tachometer
  2. B. auto level
  3. C. dumpy level
  4. D. theodolite
Answer: A. tachometer

Q4. Horizontal distance between centroids of the sections of cutting and filling is termed as.

  1. A. lift
  2. B. haulage
  3. C. carriage
  4. D. Lead
Answer: D. Lead

Q5. The ratio between original size and size on drawing sheet is called....

  1. A. diagonal
  2. B. plain scale
  3. C. Scale
  4. D. scale card
Answer: C. Scale

Q6. The way which connects two points is called....

  1. A. triangle
  2. B. Line
  3. C. polygon
  4. D. angle
Answer: B. Line

Q7. Knowledge for the internal detail after cutting plane line for a body is termed as....

  1. A. Sectioning
  2. B. Dimensioning
  3. C. Projectioning
  4. D. All of these
Answer: A. Sectioning

Q8. Name the drawing in which object opened and spread on smooth surface....

  1. A. Rotation
  2. B. development
  3. C. progression
  4. D. all of these
Answer: B. development

Q9. The process of proper and accurate measurement of all concrete ingredients for proportioning is termed as....

  1. A. placing
  2. B. Batching
  3. C. mixing
  4. D. transportation
Answer: B. Batching

Q10. Red hematite is an ore of....

  1. A. copper
  2. B. Iron
  3. C. aluminum
  4. D. brass
Answer: B. Iron

Q11. The ingredient which provide color to the paint is called.....

  1. A. Base
  2. B. vehicle
  3. C. pigment
  4. D. all of these
Answer: C. pigment

Q12. Scratching of old plaster or paint is called....

  1. A. rendering
  2. B. pealing
  3. C. Hacking
  4. D. dubbing
Answer: B. pealing

Q13. Fore bearing of AB is 110 degree; its back bearing will be....

  1. A. 315-degree
  2. B. 240-degree
  3. C. 280-degree
  4. D. 290-degree
Answer: D. 290-degree

Q14. At the end of useful life of a building value of its dismantled material is called....

  1. A. gross value
  2. B. value
  3. C. Cost
  4. D. scrap value
Answer: D. scrap value

Q15. Cross slope/Transverse slope provided in metaled width of road....

  1. A. country slope
  2. B. Gradient
  3. C. camber
  4. D. cross slope

Q16. A cross drainage work in which natural drain passes over the canal....

  1. A. level crossing
  2. B. aqueduct
  3. C. Outlet

Q17. This command is in modifying tool bar....

  1. A. poly line
  2. B. make block
  3. C. Line

Q18. The temporary structure constructed to support a safe working plate form for working is called...

  1. A. Form work
  2. B. shoring
  3. C. under pinning
  4. D. scaffolding
Answer: D. scaffolding

Q19. Equivalent length of column with one end fixed and other free...

  1. A. 1/2 L or 0.5 L

Q20. Compressive member of truss is called...

  1. A. node
  2. B. strut
  3. C. Tie

Q21. A perfect frame is judged with the following relation with number of member (n) and No. of joints (j)....

  1. A. n<2j-4
  2. B. n = 2j-3
  3. C. n<2j-3

Q22. A wall that supports soil or dry material at its back is called...

  1. A. Dam
  2. B. surcharge wall
