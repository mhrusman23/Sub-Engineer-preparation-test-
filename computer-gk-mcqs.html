Q1. How many bits make up one byte?

  1. A. 4
  2. B. 2
  3. C. 16
  4. D. 8
Answer: D. 8

Q2. Which component is called the brain of a computer?

  1. A. CPU
  2. B. Keyboard
  3. C. Mouse
  4. D. Monitor
Answer: A. CPU

Q3. RAM is a:

  1. A. Optical disk
  2. B. Permanent memory
  3. C. Volatile memory
  4. D. Printer
Answer: C. Volatile memory

Q4. The inventor of the World Wide Web is:

  1. A. Bill Gates
  2. B. Mark Zuckerberg
  3. C. Steve Jobs
  4. D. Tim Berners-Lee
Answer: D. Tim Berners-Lee

Q5. Which of these is an input device?

  1. A. Printer
  2. B. Speaker
  3. C. Monitor
  4. D. Keyboard
Answer: D. Keyboard

Q6. Which of these is an output device?

  1. A. Monitor
  2. B. Mouse
  3. C. Keyboard
  4. D. Scanner
Answer: A. Monitor

Q7. One kilobyte is commonly taken as how many bytes?

  1. A. 1024
  2. B. 1000 bits
  3. C. 100
  4. D. 8
Answer: A. 1024

Q8. The binary number system uses the digits:

  1. A. 0 and 1
  2. B. 0 to 7
  3. C. 0 to 9
  4. D. 1 to 8
Answer: A. 0 and 1

Q9. The full form of USB is:

  1. A. Universal System Bus
  2. B. Unified Serial Bus
  3. C. Universal Serial Bus
  4. D. United Serial Board
Answer: C. Universal Serial Bus

Q10. The full form of URL is:

  1. A. Uniform Resource Locator
  2. B. Unique Resource Locator
  3. C. Uniform Reference Line
  4. D. Universal Resource Link
Answer: A. Uniform Resource Locator

Q11. What is the primary function of an operating system in a computer?

  1. A. To perform complex mathematical calculations
  2. B. To manage hardware resources and software applications
  3. C. To protect the system from physical damage
  4. D. To design web pages and graphics
Answer: B. To manage hardware resources and software applications

Q12. Which of the following refers to temporary storage that loses its data when the power is turned off?

  1. A. Hard Disk Drive
  2. B. Read-Only Memory
  3. C. Random Access Memory
  4. D. Flash Drive
Answer: C. Random Access Memory

Q13. What does the acronym HTTP stand for in web addresses?

  1. A. Hypertext Transfer Protocol
  2. B. Hyperlink Transmission Text Program
  3. C. High Transfer Technology Protocol
  4. D. Hypertext Transfer Program
Answer: A. Hypertext Transfer Protocol

Q14. Which type of software is designed specifically to damage, disrupt, or gain unauthorized access to a computer system?

  1. A. Utility software
  2. B. Malware
  3. C. Application software
  4. D. Open-source software
Answer: B. Malware

Q15. Which network topology connects all devices to a single central hub or switch?

  1. A. Bus topology
  2. B. Ring topology
  3. C. Star topology
  4. D. Mesh topology
Answer: C. Star topology

Q16. What is the term for a self-contained unit of information that is sent across a computer network?

  1. A. Packet
  2. B. Sector
  3. C. Cluster
  4. D. Block
Answer: A. Packet
