TOEFL Reading MCQs (IELTS & English Tests)

Free MCQs with answers for TOEFL Reading. 20 questions in 2 chapter tests are in the app; all are shown here.

Q1. TOEFL iBT Reading passages are mostly:

  1. A. Fiction stories
  2. B. Academic texts
  3. C. Advertisements
  4. D. Personal letters
Answer: B. Academic texts

Q2. A 'vocabulary question' in TOEFL Reading asks for:

  1. A. The main idea
  2. B. The closest meaning of a word
  3. C. The author's name
  4. D. A summary
Answer: B. The closest meaning of a word

Q3. An inference question asks you to:

  1. A. Find a stated fact
  2. B. Conclude something implied by the text
  3. C. Translate a sentence
  4. D. Count paragraphs
Answer: B. Conclude something implied by the text

Q4. 'The passage states that...' questions are answered by:

  1. A. Guessing
  2. B. Locating explicit information
  3. C. Outside knowledge
  4. D. The introduction only
Answer: B. Locating explicit information

Q5. A good strategy for TOEFL Reading is to:

  1. A. Read the whole passage three times first
  2. B. Read questions and search for answers
  3. C. Skip all long passages
  4. D. Memorise the passage
Answer: B. Read questions and search for answers

Q6. Reference questions ('The word 'it' refers to...') test:

  1. A. Grammar of pronouns
  2. B. Spelling
  3. C. Pronunciation
  4. D. Handwriting
Answer: A. Grammar of pronouns

Q7. The summary question is worth:

  1. A. No points
  2. B. More points than other questions
  3. C. Half a point
  4. D. Negative points
Answer: B. More points than other questions

Q8. In TOEFL, 'prose summary' choices that are wrong usually:

  1. A. Are too short
  2. B. Contain minor details or wrong information
  3. C. Use simple words
  4. D. Come first
Answer: B. Contain minor details or wrong information

Q9. TOEFL Reading is delivered:

  1. A. On paper
  2. B. On a computer
  3. C. By telephone
  4. D. In an interview
Answer: B. On a computer

Q10. To manage time in Reading, you should:

  1. A. Spend 20 minutes on one question
  2. B. Keep a steady pace and not get stuck
  3. C. Answer only easy sections
  4. D. Leave the last passage
Answer: B. Keep a steady pace and not get stuck

Q11. A 'rhetorical purpose' question asks:

  1. A. For a fact
  2. B. Why the author mentions something
  3. C. For a date
  4. D. For spelling
Answer: B. Why the author mentions something

Q12. Negative factual questions ('EXCEPT / NOT mentioned') require you to:

  1. A. Find the one option not supported by the passage
  2. B. Find any true statement
  3. C. Guess
  4. D. Read the title
Answer: A. Find the one option not supported by the passage

Q13. The best way to handle a long passage is to:

  1. A. Memorise it
  2. B. Read for structure and main ideas, then search for details per question
  3. C. Skip it
  4. D. Read only the last paragraph
Answer: B. Read for structure and main ideas, then search for details per question

Q14. Vocabulary questions can usually be solved by:

  1. A. The word alone
  2. B. Context clues around the word
  3. C. Guessing the longest option
  4. D. The first option
Answer: B. Context clues around the word

Q15. Sentence insertion questions test:

  1. A. Spelling
  2. B. Logical flow and connection words
  3. C. Pronunciation
  4. D. Speed
Answer: B. Logical flow and connection words

Q16. If two options are opposites, often:

  1. A. Both are wrong
  2. B. One of them is correct
  3. C. Both are correct
  4. D. The question is cancelled
Answer: B. One of them is correct

Q17. Chronology/structure questions ask about:

  1. A. Word meanings
  2. B. How the passage is organised
  3. C. The author's age
  4. D. Pictures
Answer: B. How the passage is organised

Q18. You should answer questions in order because:

  1. A. It is a rule
  2. B. Questions roughly follow the passage order
  3. C. The computer forces it
  4. D. It looks neat
Answer: B. Questions roughly follow the passage order

Q19. A detail supported by the passage must be:

  1. A. Your opinion
  2. B. Stated or clearly implied in the text
  3. C. Generally true in the world
  4. D. In the first line
Answer: B. Stated or clearly implied in the text

Q20. Running out of time, the best move is:

  1. A. Leave blanks
  2. B. Answer every remaining question with your best guess
  3. C. Restart
  4. D. Read slower
Answer: B. Answer every remaining question with your best guess
