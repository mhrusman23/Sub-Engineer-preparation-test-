Q1. In an 'agree or disagree' essay, you must:

  1. A. Only list facts
  2. B. Give a clear opinion and support it
  3. C. Describe a chart
  4. D. Write a letter
Answer: B. Give a clear opinion and support it

Q2. A 'discussion' essay asks you to:

  1. A. Discuss both views and give your opinion
  2. B. Only agree
  3. C. Only disagree
  4. D. Tell a story
Answer: A. Discuss both views and give your opinion

Q3. The best number of body paragraphs is usually:

  1. A. One
  2. B. Two or three, each with one main idea
  3. C. Seven
  4. D. None
Answer: B. Two or three, each with one main idea

Q4. A topic sentence in a paragraph:

  1. A. Ends the paragraph
  2. B. States the paragraph's main idea
  3. C. Is a question
  4. D. Is an example
Answer: B. States the paragraph's main idea

Q5. 'On the other hand' is used to:

  1. A. Add a similar idea
  2. B. Introduce a contrasting idea
  3. C. Conclude
  4. D. Give a statistic
Answer: B. Introduce a contrasting idea

Q6. Which is the best way to support an idea?

  1. A. Repeat it five times
  2. B. Explain it and give a relevant example
  3. C. Write it in capital letters
  4. D. Leave it unsupported
Answer: B. Explain it and give a relevant example

Q7. The conclusion should:

  1. A. Introduce a brand-new argument
  2. B. Restate your position and main points
  3. C. Be a question
  4. D. Copy the introduction exactly
Answer: B. Restate your position and main points

Q8. In a 'problems and solutions' essay, body paragraphs should cover:

  1. A. Only problems
  2. B. Problems in one paragraph and solutions in another
  3. C. Only your childhood
  4. D. Only statistics
Answer: B. Problems in one paragraph and solutions in another

Q9. Formal essay style means you should avoid:

  1. A. Linking words
  2. B. Contractions and slang
  3. C. Examples
  4. D. Paragraphs
Answer: B. Contractions and slang

Q10. 'Furthermore' and 'Moreover' are used to:

  1. A. Contrast
  2. B. Add another supporting point
  3. C. Conclude
  4. D. Apologise
Answer: B. Add another supporting point

Q11. A balanced view in a two-sided essay means:

  1. A. No opinion at all
  2. B. Considering both sides fairly before concluding
  3. C. Only one side
  4. D. Equal word count only
Answer: B. Considering both sides fairly before concluding

Q12. Which opening is most formal?

  1. A. 'Loads of kids these days...'
  2. B. 'In recent years, there has been growing debate about...'
  3. C. 'You know what?...'
  4. D. 'Hey everyone...'
Answer: B. 'In recent years, there has been growing debate about...'

Q13. 'This essay will discuss...' is an example of:

  1. A. A conclusion
  2. B. A roadmap sentence in the introduction
  3. C. An example
  4. D. A statistic
Answer: B. A roadmap sentence in the introduction

Q14. Paraphrasing the question in the introduction:

  1. A. Is forbidden
  2. B. Is expected and shows vocabulary range
  3. C. Loses marks always
  4. D. Is the conclusion
Answer: B. Is expected and shows vocabulary range

Q15. If you run out of time, it is most important to:

  1. A. Leave the essay without a conclusion
  2. B. Write a short conclusion to complete the essay
  3. C. Start a new paragraph
  4. D. Rewrite the introduction
Answer: B. Write a short conclusion to complete the essay

Q16. Collocations like 'pose a threat' help your score because they show:

  1. A. Grammar only
  2. B. Natural, accurate vocabulary use
  3. C. Speed
  4. D. Handwriting
Answer: B. Natural, accurate vocabulary use

Q17. In an 'advantages and disadvantages' essay, you should:

  1. A. Only write advantages
  2. B. Cover both sides, and give your opinion if asked
  3. C. Write a story
  4. D. Use bullet points
Answer: B. Cover both sides, and give your opinion if asked

Q18. A complex sentence contains:

  1. A. One simple idea
  2. B. A main clause and at least one subordinate clause
  3. C. Only three words
  4. D. No verb
Answer: B. A main clause and at least one subordinate clause

Q19. 'In conclusion' and 'To sum up' are:

  1. A. Opening phrases
  2. B. Concluding phrases
  3. C. Examples
  4. D. Questions
Answer: B. Concluding phrases

Q20. The examiner mainly rewards essays that:

  1. A. Are very long only
  2. B. Fully answer the question with organised, developed ideas
  3. C. Use the hardest words
  4. D. Agree with the examiner
Answer: B. Fully answer the question with organised, developed ideas
