Q1. SDLC stands for software development:

  1. A. Language code
  2. B. Life cycle
  3. C. Layer control
  4. D. Logic cycle
Answer: B. Life cycle

Q2. Which model is a linear sequential software process model?

  1. A. Agile
  2. B. Scrum
  3. C. Spiral
  4. D. Waterfall
Answer: D. Waterfall

Q3. Which of these is an Agile framework?

  1. A. ER diagram
  2. B. UML
  3. C. SQL
  4. D. Scrum
Answer: D. Scrum

Q4. Testing individual units of code is called:

  1. A. Unit testing
  2. B. System testing
  3. C. Load testing
  4. D. Acceptance testing
Answer: A. Unit testing

Q5. UML is used for:

  1. A. Browsing the web
  2. B. Modelling software design
  3. C. Compiling code
  4. D. Encrypting data
Answer: B. Modelling software design

Q6. A requirement that describes what the system should do is a:

  1. A. Non-functional requirement
  2. B. Hardware spec
  3. C. Functional requirement
  4. D. Legal clause
Answer: C. Functional requirement

Q7. Version control tools like Git are used to:

  1. A. Create invoices
  2. B. Test hardware
  3. C. Design logos
  4. D. Track changes in code
Answer: D. Track changes in code

Q8. Refactoring means:

  1. A. Adding new features
  2. B. Improving code structure without changing behaviour
  3. C. Deleting tests
  4. D. Changing the language
Answer: B. Improving code structure without changing behaviour

Q9. Black-box testing focuses on:

  1. A. Inputs and outputs without internal code
  2. B. Internal code structure
  3. C. Hardware circuits
  4. D. Network cables
Answer: A. Inputs and outputs without internal code

Q10. The maintenance phase of SDLC occurs:

  1. A. Never
  2. B. Before requirements
  3. C. During hardware purchase
  4. D. After deployment
Answer: D. After deployment

Q11. Which software architectural pattern divides an application into Model, View, and Controller?

  1. A. MVC
  2. B. API
  3. C. SDK
  4. D. IDE
Answer: A. MVC

Q12. What does the acronym API stand for in software engineering?

  1. A. Application Programming Interface
  2. B. Advanced Program Integration
  3. C. Automated Protocol Interaction
  4. D. Application Process Integration
Answer: A. Application Programming Interface

Q13. Which phase of Software Development Life Cycle (SDLC) involves gathering requirements from stakeholders?

  1. A. Design
  2. B. Testing
  3. C. Requirement Analysis
  4. D. Deployment
Answer: C. Requirement Analysis

Q14. Which of the following is a primary goal of software configuration management?

  1. A. To eliminate all bugs from the code
  2. B. To maintain a single source of truth for all software artifacts
  3. C. To design the user interface
  4. D. To perform unit testing
Answer: B. To maintain a single source of truth for all software artifacts

Q15. Which software development principle emphasizes that software should be modular and reusable?

  1. A. Encapsulation
  2. B. Polymorphism
  3. C. Modularity
  4. D. Inheritance
Answer: C. Modularity

Q16. What does the acronym UML stand for in software engineering?

  1. A. Unified Modeling Language
  2. B. Universal Methodology Logic
  3. C. User Management Layout
  4. D. Unified Machine Language
Answer: A. Unified Modeling Language

Q17. Which metric measures the number of defects found per thousand lines of code?

  1. A. Cyclomatic complexity
  2. B. Defects per KLOC
  3. C. Mean time to failure
  4. D. Code churn
Answer: B. Defects per KLOC

Q18. During which SDLC phase are user acceptance tests typically executed?

  1. A. Planning
  2. B. Design
  3. C. Implementation
  4. D. Acceptance
Answer: D. Acceptance

Q19. In the Waterfall model, which phase directly follows the requirements analysis?

  1. A. Implementation
  2. B. Design
  3. C. Testing
  4. D. Deployment
Answer: B. Design

Q20. Which software design principle states that software entities should be open for extension but closed for modification?

  1. A. Single Responsibility Principle
  2. B. Open-Closed Principle
  3. C. Dependency Inversion Principle
  4. D. Interface Segregation Principle
Answer: B. Open-Closed Principle

Q21. What is the primary purpose of Cyclomatic Complexity in software testing?

  1. A. Measuring execution speed
  2. B. Counting total lines of code
  3. C. Determining structural independence and test paths
  4. D. Calculating memory usage
Answer: C. Determining structural independence and test paths

Q22. Which design pattern provides a way to access the elements of an aggregate object sequentially without exposing its underlying representation?

  1. A. Observer Pattern
  2. B. Iterator Pattern
  3. C. Singleton Pattern
  4. D. Factory Pattern
Answer: B. Iterator Pattern

Q23. In project estimation, what does COCOMO stand for?

  1. A. Constructive Cost Model
  2. B. Common Component Modification
  3. C. Computer Control Module
  4. D. Comprehensive Cost Measurement
Answer: A. Constructive Cost Model

Q24. Which type of maintenance involves modifying software to fix latent errors discovered after deployment?

  1. A. Adaptive maintenance
  2. B. Perfective maintenance
  3. C. Preventive maintenance
  4. D. Corrective maintenance
Answer: D. Corrective maintenance

Q25. What is the main objective of smoke testing in the software development lifecycle?

  1. A. Checking deep system performance under heavy load
  2. B. Verifying basic critical functionality after a new build
  3. C. Validating database encryption protocols
  4. D. Testing user interface color contrast
Answer: B. Verifying basic critical functionality after a new build
