Q1. Malware that demands payment to restore access to files is:

  1. A. Adware
  2. B. Firmware
  3. C. Spyware
  4. D. Ransomware
Answer: D. Ransomware

Q2. Phishing commonly happens through:

  1. A. Printer faults
  2. B. Hard disk errors
  3. C. Power failure
  4. D. Fake emails or messages
Answer: D. Fake emails or messages

Q3. A strong password should be:

  1. A. Long and unique
  2. B. Your name
  3. C. Short and common
  4. D. 1234
Answer: A. Long and unique

Q4. Encryption converts plain text into:

  1. A. HTML
  2. B. Binary tape
  3. C. Cipher text
  4. D. Source code
Answer: C. Cipher text

Q5. A firewall in a network is placed mainly to:

  1. A. Speed up the CPU
  2. B. Print documents
  3. C. Filter incoming and outgoing network traffic
  4. D. Store backups
Answer: C. Filter incoming and outgoing network traffic

Q6. Two-factor authentication improves:

  1. A. Screen resolution
  2. B. Account security
  3. C. Printing speed
  4. D. File size
Answer: B. Account security

Q7. A DDoS attack aims to:

  1. A. Fix bugs
  2. B. Back up data
  3. C. Make a service unavailable
  4. D. Steal printers
Answer: C. Make a service unavailable

Q8. HTTPS uses which protocol to secure data?

  1. A. SMTP
  2. B. Telnet
  3. C. FTP
  4. D. TLS/SSL
Answer: D. TLS/SSL

Q9. Social engineering attacks mainly exploit:

  1. A. Power cables
  2. B. Screen size
  3. C. Human behaviour
  4. D. Hardware faults
Answer: C. Human behaviour

Q10. Regular software updates mainly help to:

  1. A. Delete files
  2. B. Fix security vulnerabilities
  3. C. Slow the computer
  4. D. Change passwords
Answer: B. Fix security vulnerabilities

Q11. Which type of malware disguises itself as legitimate software to deceive users?

  1. A. Worm
  2. B. Trojan Horse
  3. C. Spyware
  4. D. Adware
Answer: B. Trojan Horse

Q12. Which RAID level provides striping with parity for fault tolerance?

  1. A. RAID 0
  2. B. RAID 1
  3. C. RAID 5
  4. D. RAID 10
Answer: C. RAID 5

Q13. Which of the following is an example of asymmetric encryption?

  1. A. AES
  2. B. DES
  3. C. RSA
  4. D. 3DES
Answer: C. RSA

Q14. What is the term for a software vulnerability that is unknown to the vendor and has no patch available?

  1. A. Phishing
  2. B. Zero-day exploit
  3. C. Malware
  4. D. Backdoor
Answer: B. Zero-day exploit

Q15. What is the main purpose of a firewall in network security?

  1. A. To speed up internet connection
  2. B. To filter incoming and outgoing network traffic
  3. C. To store backup files
  4. D. To translate domain names
Answer: B. To filter incoming and outgoing network traffic
