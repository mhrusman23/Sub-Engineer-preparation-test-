Q1. In IT general controls, 'segregation of duties' means:

  1. A. One person does everything
  2. B. No single person controls all parts of a critical process
  3. C. Duties are secret
  4. D. Work is outsourced
Answer: B. No single person controls all parts of a critical process

Q2. Change management controls ensure that program changes are:

  1. A. Made by anyone
  2. B. Authorised, tested and documented
  3. C. Hidden
  4. D. Made at night
Answer: B. Authorised, tested and documented

Q3. Encryption protects data by:

  1. A. Deleting it
  2. B. Converting it into coded form readable only with a key
  3. C. Copying it
  4. D. Compressing it
Answer: B. Converting it into coded form readable only with a key

Q4. A disaster recovery plan focuses on:

  1. A. Marketing
  2. B. Restoring IT systems and data after a disruption
  3. C. Hiring
  4. D. Office design
Answer: B. Restoring IT systems and data after a disruption

Q5. An audit trail allows transactions to be:

  1. A. Deleted
  2. B. Traced from source to final report and back
  3. C. Hidden
  4. D. Printed only
Answer: B. Traced from source to final report and back

Q6. Phishing attacks try to:

  1. A. Break hardware
  2. B. Trick users into revealing credentials or installing malware
  3. C. Slow the network
  4. D. Steal electricity
Answer: B. Trick users into revealing credentials or installing malware

Q7. Access controls based on job role are called:

  1. A. Random access
  2. B. Role-based access control (RBAC)
  3. C. Open access
  4. D. Guest access
Answer: B. Role-based access control (RBAC)

Q8. Data backup testing is important because:

  1. A. Backups look tidy
  2. B. Untested backups may fail when needed most
  3. C. It uses storage
  4. D. Managers require it
Answer: B. Untested backups may fail when needed most

Q9. In database management, the property that ensures all operations within a transaction complete successfully or the entire transaction is aborted is called:

  1. A. Atomicity
  2. B. Consistency
  3. C. Isolation
  4. D. Durability
Answer: A. Atomicity

Q10. Which of the following frameworks is most commonly used by organizations to design, implement, and monitor internal controls over information technology?

  1. A. COBIT
  2. B. GAAP
  3. C. ISO 9001
  4. D. Basel III
Answer: A. COBIT

Q11. When evaluating system interfaces, the practice of checking input data for correct type, format, and range before processing is referred to as:

  1. A. Input validation
  2. B. Output reconciliation
  3. C. Batch hashing
  4. D. Sequence checking
Answer: A. Input validation

Q12. Which malicious software pretends to be a legitimate application while secretly performing unauthorized or harmful actions?

  1. A. Ransomware
  2. B. Trojan horse
  3. C. Worm
  4. D. Spyware
Answer: B. Trojan horse

Q13. A complete duplicate of a primary data center that maintains real-time data replication and can take over operations almost instantly during a disruption is known as a:

  1. A. Cold site
  2. B. Warm site
  3. C. Hot site
  4. D. Mobile site
Answer: C. Hot site

Q14. Which type of control is designed to discover errors or unauthorized events after they have already occurred?

  1. A. Preventive control
  2. B. Detective control
  3. C. Corrective control
  4. D. Directive control
Answer: B. Detective control

Q16. Which of the following best describes the main objective of a SOC 2 report?

  1. A. Assessing tax compliance and filings
  2. B. Evaluating controls related to Security, Availability, Processing Integrity, Confidentiality, or Privacy
  3. C. Certifying financial statement accuracy for public investors
  4. D. Auditing corporate governance structures and board decisions

Q17. What is the primary focus of a SOC 1 report compared to a SOC 2 report?

  1. A. Internal controls over financial reporting
  2. B. Network vulnerability assessments
  3. C. Physical data center security only
  4. D. Software development lifecycle standards
Answer: A. Internal controls over financial reporting

Q18. What is a key requirement regarding data retention policies within an organization's data governance framework?

  1. A. Keeping all operational data indefinitely without deletion
  2. B. Establishing clear timelines for how long records must be kept and ensuring secure disposal
