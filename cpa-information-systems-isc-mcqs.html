Q1. In IT general controls, 'segregation of duties' means:

  1. A. One person does everything
  2. B. No single person controls all parts of a critical process
  3. C. Duties are secret
  4. D. Work is outsourced
Answer: B. No single person controls all parts of a critical process

Q2. A firewall is used to:

  1. A. Speed up processing
  2. B. Block unauthorised network access
  3. C. Store backups
  4. D. Print reports
Answer: B. Block unauthorised network access

Q3. Change management controls ensure that program changes are:

  1. A. Made by anyone
  2. B. Authorised, tested and documented
  3. C. Hidden
  4. D. Made at night
Answer: B. Authorised, tested and documented

Q4. Encryption protects data by:

  1. A. Deleting it
  2. B. Converting it into coded form readable only with a key
  3. C. Copying it
  4. D. Compressing it
Answer: B. Converting it into coded form readable only with a key

Q5. A disaster recovery plan focuses on:

  1. A. Marketing
  2. B. Restoring IT systems and data after a disruption
  3. C. Hiring
  4. D. Office design
Answer: B. Restoring IT systems and data after a disruption

Q6. Two-factor authentication requires:

  1. A. Two passwords
  2. B. Two different types of proof, e.g. password plus a phone code
  3. C. Two users
  4. D. Two computers
Answer: B. Two different types of proof, e.g. password plus a phone code

Q7. An audit trail allows transactions to be:

  1. A. Deleted
  2. B. Traced from source to final report and back
  3. C. Hidden
  4. D. Printed only
Answer: B. Traced from source to final report and back

Q8. Phishing attacks try to:

  1. A. Break hardware
  2. B. Trick users into revealing credentials or installing malware
  3. C. Slow the network
  4. D. Steal electricity
Answer: B. Trick users into revealing credentials or installing malware

Q9. Access controls based on job role are called:

  1. A. Random access
  2. B. Role-based access control (RBAC)
  3. C. Open access
  4. D. Guest access
Answer: B. Role-based access control (RBAC)

Q10. Data backup testing is important because:

  1. A. Backups look tidy
  2. B. Untested backups may fail when needed most
  3. C. It uses storage
  4. D. Managers require it
Answer: B. Untested backups may fail when needed most
